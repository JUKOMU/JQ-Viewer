# 7. 下载

从主侧边栏进入“下载”，可以查看下载任务、阅读已经准备好的内容，也可以将下载图片导出成文件，或导入设备上已有的 PDF、CBZ。

创建下载任务的入口分布在作品详情、搜索、分类和收藏夹等页面。选择具体章节的步骤见[“作品详情与阅读”一章](reading.md)；本章从任务已经提交、进入下载页后开始说明。

<a id="download-page"></a>

## 7.1 认识下载页的两个视图

页面顶部有“下载”和“导出”两个主视图：

| 主视图 | 展示内容 | 常用操作 |
| --- | --- | --- |
| 下载 | 图片下载任务、已经完成下载的作品与章节 | 暂停、继续、重试、阅读、删除，以及发起文件导出 |
| 导出 | 文件管理和导出任务 | 导入、查找和阅读本地文件，校验文件，查看导出状态，管理文件与任务记录 |

“导出”视图中还有“文件”“导出任务”两个标签。查看已经生成或导入的文件，选择“文件”；检查导出是否结束或为什么失败，选择“导出任务”。

这三类内容分别管理：

- **下载图片**：作为章节图片下载到设备，供图片阅读器和导出使用。
- **本地文件**：已导出的文件，或已经登记的 PDF、CBZ 文件。
- **导出任务记录**：记录一次导出的状态和进度。

后面的删除操作会针对不同内容产生影响，执行前先确认所在视图和操作名称。

<a id="download-tasks"></a>

## 7.2 查看和控制下载任务

### 分组、排序与进度

“下载”视图将内容分为“下载中”“已完成”“下载失败”。“下载中”组也包含排队、暂停和校验中的任务。

点击组标题可以展开或收起。内容较多时，向下滚动会继续加载；如果当前只保留了后面的内容，可以使用“加载上一页”补看之前的条目。触控设备可在退出多选后下拉刷新。

页面上方的排序按钮依次切换时间、标题、ID 和作者排序，旁边的箭头切换升序或降序。页面取得存储信息时，还会显示下载占用和设备可用空间。

任务卡片按当前状态显示进度：

| 状态 | 含义与下一步 |
| --- | --- |
| 排队中 | 已创建任务，等待下载 |
| 下载中 | 显示已下载页数、总页数、百分比，以及可用的速度信息 |
| 已暂停 | 任务暂时停止，可以选择“继续” |
| 校验中 | 正在确认下载结果；此状态不提供取消或多选 |
| 已完成 | 可以阅读或导出；多章节作品会按作品聚合展示 |
| 下载失败 | 查看错误提示；部分失败时会显示已下载页数和失败数量 |

### 暂停、继续、重试与取消

点击任务卡片右侧的“更多操作”（竖向省略号），按状态选择：

- **暂停**：暂停正在下载的任务，保留已下载内容，后续可以继续。
- **继续**：恢复已暂停任务。
- **重试／重新下载失败图片**：重新提交失败章节的下载处理，完成后再核对任务状态。
- **取消**：终止排队、下载中或已暂停的任务，并清理该任务对应的下载文件和记录。

**想暂时停下并保留进度时，使用“暂停”。“取消”会清理任务，当前菜单操作不会再弹出单独的取消确认。**

操作成功提交后，任务仍可能经历排队或校验；以卡片最终状态判断是否完成。任务失败时，可以先核对连接、可用空间和错误信息，再重试。

下载位置及并发相关选项在“设置”页配置，详见[“设置与下级页面”一章](settings.md)。

## 7.3 阅读与批量管理下载内容

### 阅读已完成内容

点击已完成的作品卡片：

- 单章节卡片会打开对应的已下载图片阅读器。
- 多章节作品会进入章节选择页面，再选择所需章节。

章节选择页面可以在“显示已下载”“显示全部章节”之间切换。已有本地来源的章节可以从相应内容进入阅读；查询全部章节和读取尚未下载的内容需要连接内容服务。

卡片菜单中的“进入详情页”可以返回在线作品详情，查看信息、章节和阅读来源。图片阅读器的翻页、进度恢复和设置见[“作品详情与阅读”一章](reading.md)。

### 批量操作的范围

长按可以进入允许多选的任务卡片，桌面端也可以用鼠标左键按住；卡片菜单和“已完成”“下载失败”组标题旁还提供“多选”入口。

进入多选后，可以逐项选择，或点击“全选”“反选”。这两个按钮会补读相应范围的完整分页，而不是只处理屏幕上可见的条目：

| 进入的多选范围 | 全选／反选包含什么 |
| --- | --- |
| 已完成内容 | 已完成组中可直接选择的单章节卡片；多章节聚合卡片不纳入这一全选范围 |
| 下载中或失败任务 | 下载中组和下载失败组内可操作的任务，排除校验中任务 |

多章节聚合卡片需要处理哪些章节，可以从该作品菜单的“导出”或“删除”进入章节选择面板。

下方操作按钮会根据所选任务状态出现：暂停、继续、重试、删除、导出。每个操作只处理符合其条件的条目，例如“继续”处理暂停任务，“导出”处理已经完成的任务。

核对已选数量和实际操作后再提交。批量删除会再次确认；其他操作结束后，应根据结果提示检查成功和失败项。“取消”用于退出多选，不会取消下载任务本身。

## 7.4 导出 PDF、ZIP 或 CBZ

导出使用已经完成下载的章节图片，生成单独的文件。下载页的“导出”操作与收藏夹复制文字清单的“导出”是不同入口。

### 从已完成章节发起

1. 在“下载”视图的“已完成”中，打开目标作品的“更多操作” → “导出”。
2. 在底部导出面板选择 PDF、ZIP 或 CBZ。
3. 如果有多个章节，核对要导出的章节；需要时使用全选或取消全选。
4. 选择导出目录，核对保存路径及其他选项。
5. 点击“导出”或“合并导出”。
6. 切换到“导出 → 导出任务”查看状态，再到“文件”查看结果。

也可以通过下载多选导出多个已完成的单章节任务。此批量入口按章节分别创建导出任务，不提供跨作品合并。

| 格式 | 如何使用结果 |
| --- | --- |
| PDF | 作为 PDF 文件保存；可以在应用文件列表中阅读 |
| CBZ | 保存为漫画压缩包；可以在应用文件列表中阅读 |
| ZIP | 保存为 ZIP 压缩包；可在文件管理器中处理，当前应用文件列表不提供 ZIP 阅读入口 |

这里是从下载图片生成文件，不是把已导入的 PDF、CBZ 互相转换格式。

### 导出目录与保存路径

展开面板内的“导出设置”，点击“导出位置”旁的“浏览”，通过系统目录选择窗口选定文件夹。

Android 需要按系统提示授予所选目录的访问权限；桌面端选择当前用户可写的目录。导出必须使用已选定的目录，单独输入一段路径不能代替目录选择和授权。

“目录模板”“名称模板”会生成默认保存路径。单章导出或合并导出时，可以编辑本次“保存路径”；多个章节分别导出时，各章按模板生成自己的路径，不能用一个手填路径替代所有输出名称。

手动编辑后的保存路径仍需位于已选择的目录内。想改到其他目录时，请重新点击“浏览”选择。目录失效或权限被撤销后，也需要重新选择并授权。

面板中对目录和模板的修改会保存，之后导出仍会使用。更完整的变量、条件和示例见“设置与下级页面”中的文件导出设置及“食用方法”帮助页。

### 每章一个文件与合并导出

从同一部多章节作品打开导出面板时，可以选择：

- **每章一个文件**：每个勾选的章节单独导出。
- **合并为一个文件**：至少选择同一作品的两个章节，再按章节顺序合并。

合并前核对选中章节和顺序。模板中的“{chapterRange}”可以将所选章节范围写入文件名；完整命名规则见设置章。

### 分卷与图片质量

开启“分卷导出”后，可以填写每卷最多页数，范围为 10—999 页。需要多卷时，输出文件名会附带页码范围。

例如，总计 250 页、每卷最多 100 页的“示例.pdf”，会分成：

~~~text
示例_001-100.pdf
示例_101-200.pdf
示例_201-250.pdf
~~~

合并导出开启分卷时，按合并后的总页数分卷，卷边界不一定正好位于章节之间。

PDF 还可以选择“原图”或“压缩”。压缩比控制图片长宽缩放比例，例如 0.50 表示长和宽各缩放到原来的 50%，不表示输出文件大小一定减少一半。ZIP、CBZ 不提供这组 PDF 图片质量选项。

### 同名覆盖与通知

已有同名文件时，应用会列出冲突路径并询问是否覆盖。确认覆盖前，请核对目录、文件名与格式。

一批任务中取消覆盖，只影响发生冲突的那些任务；其他已经接受的任务可能已经开始导出，需到导出任务列表核对。

Android 可能询问通知权限。暂不授权仍会继续导出，但没有对应的系统通知；可以在应用“导出任务”中查看进度。“导出已开始”或“已进入队列”只表示提交结果，不等于最终文件已经完成。

## 7.5 查看导出进度与处理失败

进入“导出 → 导出任务”，可以按任务状态和格式筛选，查看页数、分卷进度和错误信息。

| 状态 | 如何理解 |
| --- | --- |
| 排队中、导出中 | 任务等待执行或正在写入文件 |
| 取消中、已取消 | 已请求停止，或已停止且没有本次已完成的卷 |
| 已完成 | 该任务预定的输出已经完成 |
| 部分完成 | 已经完成部分卷，后续卷失败或被取消；需要逐卷核对 |
| 失败 | 任务未成功完成，查看卡片上的错误原因 |
| 已中断 | 上次运行未正常完成，需检查结果并决定是否重试 |

- **取消**：排队或导出中的任务可请求取消。已经成功写出的卷可能保留，因此还要到文件列表查看实际结果。
- **重试整个任务**：失败、部分完成、已中断或已取消的任务可以重新导出。
- **删除任务记录**：只对已结束的任务提供，清理历史，不删除最终文件。

**重试会从第一卷重新开始，并覆盖已有同名文件，不是接着失败卷往后导出。** 确认窗口会说明这一影响：写完的卷会立即替换；后续失败时，尚未处理的旧卷可能仍保留，但不计入本次结果。

完成后按任务结果、卷数和文件列表共同核对，避免把上一次留下的旧文件当作本次全部成功的结果。

任务列表顶部的多选支持按当前状态、格式筛选补读完整列表，全选或反选其中已经结束的任务。批量操作用于删除这些任务记录，不用于批量取消正在执行的任务。

## 7.6 查找、阅读与校验本地文件

进入“导出 → 文件”，可以查看已登记的导入文件与导出结果。

### 筛选与阅读

搜索框可以按标题、文件名或漫画 ID 查找。来源筛选提供“全部”“导入”“导出”“ZIP”：

- “全部”“导入”“导出”下可以继续选择 PDF、CBZ 或全部格式。
- ZIP 文件从单独的“ZIP”筛选入口查看。

文件卡片显示格式、导入／导出来源、页数、大小、关联章节情况，以及可用性状态。常见状态有“可用”“文件缺失”“无法读取”“文件损坏”和“待校验”。

点击 PDF 或 CBZ 的内容区域，可以打开整份文件阅读。通过作品详情选择某个已关联章节来源时，则按章节范围阅读；进度的区别见[“作品详情与阅读”一章](reading.md)。

文件菜单中的“进入详情页”需要该记录已经关联漫画。无法关联时，应用会提示，不能仅凭文件名保证找到详情。

### 校验、复制路径与打开目录

打开卡片的“更多操作”，可以选择：

| 操作 | 作用 |
| --- | --- |
| 校验 | 重新检查当前文件的可读取性和内容，更新记录中的状态 |
| 复制路径 | 将该记录展示的文件位置复制到剪贴板 |
| 打开文件夹 | 请求系统打开文件所在位置，具体能否打开取决于平台和文件管理器 |
| 移除 | 将记录移出文件库，保留设备上的实际文件 |
| 删除 | 删除该记录位置当前指向的实际文件，并移出文件库 |

文件在外部被移动、替换或权限变化后，可以先刷新列表并校验，按结果处理。校验更新状态，不会重新下载或修复损坏文件。

如果页面提示“文件管理记录已重置，实际文件未被删除，可重新导入”，可以重新选择原文件所在目录，按下一节登记现有文件。

## 7.7 导入已有 PDF 或 CBZ

### 扫描目录

1. 在“导出”视图点击“导入文件”。
2. 选择已有文件所在的文件夹，按系统要求授予访问权限。
3. 应用扫描 PDF 和 CBZ，进入“导入”确认页。
4. 核对每个文件对应的作品 ID 和章节，再点击“确认导入”。

这个入口通过文件夹扫描导入，当前支持 PDF、CBZ，不扫描 ZIP。导入会登记原文件的位置，不会把原文件复制成应用私有目录里的另一份；之后仍需保证原位置和访问权限有效。

### 核对 ID 与章节

确认页会显示已解析、多 ID、无 ID、ID 重复等统计，并在文件卡片中标明需要处理的问题。

应用会尝试从文件名提取作品 ID。可提取的数字串至少三位，且不以 0 开头；带有有效漫画信息的 CBZ 也可能从内嵌信息获得作品与章节线索。

如果识别不准确，可以：

- 点击卡片的编辑图标，填写或修订编号，再点击“应用”。编辑文字末尾使用“空格 + 数字”可指定章节序号，例如“123456 3”表示作品 ID 123456 的第 3 话；这是编辑示例，不保证该作品实际存在。
- 点击需要匹配的卡片，使用“搜索匹配”寻找对应作品，选择结果；多章节作品继续选择章节，再点击匹配面板中的确认按钮。
- 出现多个候选 ID 时，选择正确候选，再检查章节。

这里编辑的是应用用于匹配的文字，不会重命名磁盘上的原文件。“ID 重复”提示多个文件可能关联同一作品，应结合章节核对；它不等于这些文件一定相同。

已识别为多章节作品但尚未选定章节时，需要先完成章节选择。不能读取的文件，以及缺少有效 ID 或必需章节信息的条目，不会作为已解决条目导入。

### 确认登记

点击顶部“确认导入”时，如果还有未解决文件，应用会说明跳过数量，可以返回继续处理，也可以只导入已解决部分。

随后会询问是否添加到离线收藏夹：

- **跳过**：继续登记文件，不主动将这一批添加到离线收藏夹。
- **选择收藏夹**：选择或新建离线收藏夹，登记后同时保存相关作品条目。

完成后核对“已导入”“已存在”“错误”等数量，再回到“导出 → 文件”筛选“导入”，查看实际登记结果。同一位置已经在文件库中的文件会按已有记录处理，不会因为再次扫描就自动覆盖登记信息。

作品匹配和详情补全需要连接内容服务；图片或书目信息没有显示时，先核对 ID、章节和连接状态。已有可用文件的阅读则取决于文件本身与当前访问权限。

## 7.8 移除、删除与清空的区别

以下操作的影响不同：

| 所在位置与操作 | 会处理什么 |
| --- | --- |
| 下载任务 → 暂停 | 暂停执行，保留下载内容以便继续 |
| 下载任务 → 取消 | 终止任务，并清理对应下载文件和记录 |
| 已完成／失败下载 → 删除 | 删除对应章节的下载文件和记录，包括失败任务残留的下载内容 |
| 下载组标题 → 清空 | 对该组全部已完成或失败任务清理文件和记录，不限于已加载条目 |
| 文件 → 移除 | 只移出文件库，保留实际 PDF、CBZ 或 ZIP |
| 文件 → 删除 | 删除记录位置当前指向的实际文件，并移出文件库 |
| 导出任务 → 删除任务记录 | 只删除已结束任务的历史，保留最终文件 |

### 删除下载章节

单章节使用菜单“删除”并确认；多章节作品会打开选择面板，勾选要删除的章节，再点击底部“删除”。面板提供全选、反选和清空勾选，只有勾选的下载章节会被删除。

下载章节的删除或清空不会同时删除已经独立导出的 PDF、CBZ、ZIP，也不会取消收藏。需要删除那些文件时，到“导出 → 文件”操作。

“清空已完成”会删除所有相应下载图片和记录，不只是清空页面显示。需要保留离线阅读内容时，不要把它当作整理历史记录的按钮。

### 删除实际文件

“文件”菜单的删除确认会显示文件名、完整位置、大小、页数与状态。确认后删除的是**该位置当前指向的文件**；如果你曾在外部用另一个文件替换同名文件，替换后的当前文件也会被删除。

删除后不能从应用撤销。删除失败时查看权限和错误提示；文件已缺失时，应用可以移出对应记录。只想从应用列表隐藏记录、保留文件，请选择“移除”。

文件列表的多选同样支持按当前筛选补读全部结果，但批量按钮是“删除实际文件”，不是批量移除记录。确认时请核对显示的文件名与位置。

导出任务列表的批量删除则只删除已结束任务记录，最终文件仍保留。

## 7.9 遇到问题时

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 提交下载后还不能离线阅读 | 查看任务是否已经完成，而不是排队、暂停或校验中 |
| 想停一会儿但保留下载进度 | 选择暂停；取消会清理该任务文件和记录 |
| 下载中显示部分图片失败 | 查看错误提示，恢复连接后使用重试入口，再核对最终状态 |
| 已完成组的全选没有包含多章节作品 | 聚合卡片不在这一多选范围；从该作品菜单进入导出或删除章节面板 |
| 导出提示先选择目录，或路径无效 | 点击导出设置中的“浏览”，重新选择可写目录，确认保存路径位于该目录内 |
| 导出提示文件已经存在 | 核对路径后决定是否覆盖；取消覆盖不一定停止同批其他任务 |
| 导出显示部分完成 | 查看哪些卷已经成功；重试会从第一卷重新覆盖导出 |
| ZIP 不在普通文件列表中 | 点击“ZIP”筛选；当前应用也不提供 ZIP 阅读或 ZIP 导入入口 |
| 导入页显示多 ID、无 ID 或待选章节 | 编辑匹配文字，或使用搜索匹配并选择章节，再确认导入 |
| 导入后找不到文件 | 切到“导出 → 文件”，检查来源与格式筛选，并核对导入结果数量 |
| 文件变成缺失、无法读取或损坏 | 核对原文件是否移动、是否仍有权限，刷新并校验；需要时重新选择目录导入 |
| 想整理记录又保留实际文件 | 文件使用“移除”；导出任务使用“删除任务记录”，不要选择“删除实际文件” |
