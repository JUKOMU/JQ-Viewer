# 6. 收藏夹

“收藏夹”用于保存、查找和整理作品条目。你可以使用账号中的在线收藏，也可以在当前设备上建立离线收藏夹，将内容按自己的方式分组。

收藏条目与漫画文件分别管理。收藏一部作品后，还需要完成相应章节的下载或准备可读取的本地文件，才能使用对应的离线阅读来源。

<a id="favorite-sources"></a>

## 6.1 打开收藏夹，选择在线或离线来源

从主侧边栏点击“收藏夹”，进入收藏内容页面。点击顶部搜索框旁的文件夹图标，打开右侧收藏夹列表，再选择要查看的来源和文件夹。

窗口较窄时，收藏夹列表以覆盖在页面上的菜单展开；窗口较宽时，可以与内容区域并排显示。选中某个收藏夹后，主区域显示其中的作品。

右侧列表分成两组：

| 来源 | 内容保存在什么地方 | 使用前提 |
| --- | --- | --- |
| 在线收藏夹 | 当前在线账号的收藏与分组 | 需要登录账号，并能连接内容服务 |
| 离线收藏夹 | 当前设备的应用数据 | 可以在本地读取已保存的条目信息；图片、详情或阅读内容仍需相应的网络或本地来源 |

在线与离线收藏分别管理。将在线夹复制成离线夹，是执行一次复制；之后一边的新增、移动或删除不会自动同步到另一边。

退出在线账号后，页面会转到离线收藏，已有离线收藏不会因此清空。不同设备上的离线收藏分别保存。

### “全部”与具体收藏夹

离线收藏列表中的“全部”会汇总各个离线收藏夹，并按作品 ID 去重。同一作品保存在多个离线夹时，在“全部”中只显示一次，因此这里的数量可能小于各夹数量相加。

“全部”用于汇总查看，没有一个可以直接移除条目的单独所属夹。需要移动或取消某条离线收藏时，先进入它实际所在的具体收藏夹。

在线的“全部”入口与离线的“全部”属于不同来源，操作时先确认右侧列表中选中的分组。

<a id="browse-favorites"></a>

## 6.2 查找、浏览与阅读收藏

### 在当前收藏夹中查找

1. 在右侧列表选择要查找的收藏夹。
2. 在页面顶部“搜索收藏夹...”输入关键词。
3. 点击放大镜，或按 Enter 提交。
4. 清空关键词后再次提交，可以查看当前收藏夹的全部内容。

搜索作用于当前选中的来源与收藏夹。切换收藏夹时会清空关键词，重新从第 1 页显示。

不同视图的匹配范围如下：

| 当前视图 | 可以按什么查找 |
| --- | --- |
| 在线收藏夹，包括在线“全部” | ID 精确匹配，或标题、作者、标签中包含的文字 |
| 具体离线收藏夹 | 标题中包含的文字 |
| 离线“全部” | ID 精确匹配，或标题、作者、标签中包含的文字 |

在线收藏的关键词查找会读取当前收藏夹的各页，再筛选结果；内容较多时可能需要等待。它会查找整个当前收藏夹，范围不只限于屏幕上已加载的条目。

搜索框可以显示已有的收藏搜索历史，点击历史条目会重新提交该关键词。

### 浏览与刷新

作品区域可以切换列表或网格；网格模式可以调整列数。向下滚动接近末尾时，会继续加载后续页。

展开右下角快捷操作，可以跳页、回顶或返回上一页面。其中的放大镜会打开收藏夹列表，关键词输入仍使用顶部搜索框。

触控设备在列表顶部下拉可以刷新；如果当前加载范围不是从第 1 页开始，下拉会先用于补载前一页，可以通过跳页回到第 1 页后再刷新。

在线收藏夹列表更新失败时，可能保留上次成功获取的结果，并提示“正在显示上次结果”。这时可以点击“重试”，重新获取列表。

### 查看详情、阅读和下载

- **点击作品卡片**：打开作品详情，查看信息、选择章节和阅读来源，具体见[“作品详情与阅读”一章](reading.md)。
- **卡片“更多操作” → 阅读**：尝试获取章节并打开图片阅读器。该快捷入口会请求章节信息；离线阅读已有文件或下载内容，可以从下载页进入。
- **卡片“更多操作” → 下载**：获取章节并创建下载任务，成功提交后到“下载”页查看进度。

收藏页的快捷下载按获取到的章节创建任务。多章节作品需要指定章节时，应先进入详情页选择；这里的“下载”不表示自动下载整部作品的全部章节。

条目上的本地内容标记用于提示已完成下载或已有导入记录，不能据此判断所有章节都已准备好。具体章节和文件是否可用，请在详情或下载页核对。

## 6.3 移动或取消单个收藏

### 移动到另一个收藏夹

1. 进入该条目所在的具体收藏夹。
2. 点击卡片的“更多操作”（竖向省略号），选择“移动”。
3. 在“移动到”窗口中选择目标收藏夹。
4. 点击“确定”，等待操作结果，再核对目标夹。

条目移动在同一种来源内进行：在线条目移动到另一个在线夹，离线条目移动到另一个离线夹。需要将整个夹复制到另一种来源时，使用本章后面的收藏夹复制功能。

如果提示“没有其他收藏夹”，先在相应来源下新建一个目标夹，再执行移动。离线“全部”中的条目不能直接执行移动，需要进入具体离线夹。

移动失败时，先核对来源和目标中的实际内容，再决定是否重试。

### 取消收藏

1. 在具体收藏夹中，点击条目的“更多操作” → “取消收藏”。
2. 核对确认窗口中的作品名称。
3. 点击“移除”。

在线取消收藏会向内容服务提交取消收藏操作。离线取消收藏只移除该作品在当前离线夹中的条目；其他离线夹里同一作品的副本仍保留。

取消收藏不会同时删除已经下载的漫画图片或本地 PDF、CBZ 文件。文件删除与下载记录管理见[“下载”一章](downloads.md)。

## 6.4 批量处理收藏条目

长按作品卡片可以进入多选；桌面端可以用鼠标左键按住卡片，也可以从卡片“更多操作”中选择“多选”。

进入多选后，可以逐项点击卡片，也可以使用“全选”“反选”。顶部显示已选数量，下方显示当前可用的批量操作。

### 全选与反选的范围

收藏页会补读当前收藏夹、当前关键词条件下的全部结果，再执行全选或反选。

例如，当前夹中有 200 条，搜索后有 30 条匹配，“全选”会选择这 30 条，即使屏幕上目前只加载了其中一部分。没有关键词时，范围就是当前夹的全部结果。

这与普通搜索、分类结果页中仅针对已加载条目的全选范围不同。读取完整收藏内容期间会显示等待状态；出现“读取完整收藏夹失败，本次选择未生效”时，请先处理连接或读取问题，再重新选择。

### 执行批量操作

| 操作 | 使用方式与影响 |
| --- | --- |
| 下载 | 逐项获取章节并提交下载队列；提交后到下载页查看实际进度 |
| 移动 | 选择同一种来源内的目标收藏夹，将所选条目移过去 |
| 取消收藏 | 移除所选条目在当前来源中的收藏；离线来源只移除当前夹中的记录 |
| 取消 | 清空选择并退出多选状态 |

离线“全部”视图的批量操作只提供下载；移动与取消收藏需要进入具体离线夹。

**多选中的“取消收藏”会直接开始执行，当前正式版没有单个条目移除时的再次确认窗口。** 点击前请核对来源、文件夹、关键词和已选数量。

移动或取消收藏出现进度遮罩时，保持应用开启，等待结果提示。出现部分成功、部分失败时，应到来源与目标夹核对，不能把已选数量当作成功数量。

部分移动流程会保留临时备份并给出提示。请保留提示信息，再核对条目实际所在位置；当前页面没有直接恢复这些备份的按钮，也不能把“备份已保留”理解为操作已经自动回滚。

## 6.5 创建、重命名与删除收藏夹

文件夹管理入口位于右侧收藏夹列表。这里的操作针对文件夹；卡片菜单针对单个作品，两者的作用范围不同。

### 新建与重命名

- **新建**：点击“在线收藏夹”或“离线收藏夹”标题旁的加号，填写名称并确认。新建在线夹需要登录并连接内容服务。
- **重命名**：点击具体文件夹旁的“更多操作” → “重命名”，输入新名称并确认。

在线“全部”和离线“全部”不提供重命名或删除菜单。普通离线夹按具体文件夹管理，即使它的名称是“默认收藏夹”，也应以实际菜单提供的操作为准。

### 删除收藏夹

1. 打开待删除文件夹的“更多操作” → “删除”。
2. 核对弹窗中的文件夹名称。
3. 确认后点击“删除”。

**删除离线收藏夹会同时删除该夹内的收藏条目。** 其他夹中的同一作品副本，以及已经下载或导入的漫画文件，不随该操作删除。

在线删夹交由内容服务处理，应用不提供撤销入口。需要保留条目时，可以先移动到其他在线夹，或复制到离线夹，再删除源夹；删除后到在线“全部”及相关夹中核对结果。

<a id="copy-folders"></a>

## 6.6 复制收藏夹与同步到在线

在右侧收藏夹列表中，打开某个文件夹的“更多操作” → “复制”。复制按完整文件夹内容执行，不受主区域关键词或多选结果限制。

### 在线收藏夹复制到离线

1. 选择在线收藏夹的“复制”。
2. 在“复制到离线收藏夹”窗口填写新文件夹名称。
3. 点击“确定”，等待复制完成。
4. 到离线收藏夹列表中查看新建的副本。

应用会读取在线源夹的全部页，将条目信息保存到新建的离线夹，保留在线源夹的内容。此操作保存收藏条目，不会同时下载漫画图片。

### 离线副本与同步到在线

复制离线收藏夹时，可以选择：

| 选项 | 结果 |
| --- | --- |
| 离线副本 | 新建离线夹，复制源夹的条目，保留源夹 |
| 同步到在线 | 新建在线夹，把离线条目加入或移动到该在线夹，保留离线源夹 |

填写新名称、选择目标方式后，再点击“确定”。“同步到在线”需要登录并能连接内容服务，建议使用与现有在线夹不同的名称，便于核对新建目标。

**已经在线收藏的同一作品也会被移动到这次新建的在线夹，原来的在线分组可能因此变化。** 同步完成后，应查看新建在线夹和原有分组，核对结果。

这里的“同步到在线”是一次操作，之后两边不会持续自动同步。出现部分失败提示时，按提示检查未成功的条目。

离线“全部”也可以使用复制：应用会先按作品 ID 去重，再生成离线副本或执行同步到在线。原有离线文件夹结构不会通过这次复制原样重建到目标来源。

<a id="move-folder-contents"></a>

## 6.7 移动整个收藏夹的内容

收藏夹菜单中的“移动”处理该夹的全部条目，用于把内容集中到另一夹。它不只处理屏幕上当前可见或搜索匹配的部分。

1. 在右侧列表打开源收藏夹的“更多操作” → “移动”。
2. 选择同一种来源中的目标收藏夹。
3. 核对窗口中的源夹与目标，再点击“确定”。
4. 等待结果，并到两边查看内容。

在线夹的内容移动到其他在线夹，离线夹的内容移动到其他离线夹。此入口转移内容，不会自动删除源文件夹本身；需要删除空夹时，再单独操作。

### 离线具体文件夹与“全部”的区别

- **从具体离线夹移动**：把这个夹的条目移到目标夹，按作品 ID 避免在目标夹中重复添加，源夹内容清空。
- **从离线“全部”移动**：把所有离线夹的条目按 ID 合并到目标夹，清空其他离线夹里的条目；各文件夹本身仍保留。

例如，“待读”和“整理中”都保存了同一作品，从离线“全部”移动到“总收藏”后，该作品在目标夹只保留一条，另外两个夹中的条目会被清空。

希望保留原有分组时，应使用“复制”。执行整夹移动前，尤其要确认当前操作的是具体离线夹还是离线“全部”。

## 6.8 导出收藏夹文本

收藏夹的“导出”用于生成作品文字清单，并复制到剪贴板，方便粘贴到其他应用中保存。

1. 在右侧收藏夹列表中，找到需要导出的文件夹。
2. 点击该夹的“更多操作” → “导出”。
3. 等待应用读取完整内容。
4. 出现“已复制若干条到剪贴板”后，切到需要保存文本的应用中粘贴。

如果系统或运行环境不能写入剪贴板，应用会打开“导出结果”窗口，在文本框中展示结果，可以手动复制。

导出范围是所选文件夹的完整内容，与主区域的关键词和多选状态无关。离线“全部”按 ID 去重导出；在线导出需要读取内容服务的各页。

### 文本格式从哪里设置

每个作品按一行输出，行内格式使用“设置 → 收藏夹导出设置 → 导出格式模板”。默认格式为：

~~~text
JM{id}{title}
~~~

例如，示例 ID 为“123456”、标题为“示例作品”时，默认输出：

~~~text
JM123456示例作品
~~~

只需要编号时，可以将模板设为“{id}”。设置页同时提供可用变量与预览；变量含义、修改和重置方式见[收藏夹导出格式](settings.md#favorite-export-format)。

复制得到的文本适合保存编号和作品信息。它不包含漫画图片、文件夹结构或可直接恢复全部收藏的备份数据。漫画文件的 PDF、CBZ 等导出操作见[“下载”一章](downloads.md)，文件目录与文件名模板也由相应导出设置控制。

## 6.9 遇到问题时

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 看不到在线收藏夹，或在线操作失败 | 检查是否已登录，以及是否能连接内容服务；未登录时可以使用离线收藏 |
| 更新失败后仍显示一些文件夹 | 当前可能显示上次成功的结果；按错误提示点击“重试”获取最新列表 |
| 离线夹中按作者或 ID 搜不到 | 具体离线夹按标题查找；切到离线“全部”可以按 ID、标题、作者或标签查找 |
| 离线“全部”数量小于各夹数量之和 | “全部”按作品 ID 去重，同一作品在多个夹中只算一次 |
| 想移动条目，却提示“没有其他收藏夹” | 先在同一种来源下新建目标夹 |
| 离线“全部”中无法取消或移动某个条目 | 先进入条目所在的具体离线夹；“全部”的整夹移动则是合并所有离线内容 |
| 全选后的数量比屏幕可见条目多 | 全选会补读当前收藏夹及搜索条件下的全部结果 |
| 同步到在线后，原有在线分组变了 | 已经在线收藏的作品会被移动到新建目标夹；核对该夹与原分组 |
| 导出后找不到生成的文件 | 收藏夹导出结果在剪贴板或“导出结果”窗口中，请粘贴或复制到其他应用保存 |
| 有离线收藏却仍不能离线阅读 | 离线收藏保存条目信息；到下载页确认所需章节或文件已经准备好 |
| 移动只成功了一部分，或提示保留备份 | 保留提示，核对来源与目标的实际内容；备份保留提示不代表已经回滚，页面也没有直接恢复备份的入口 |
