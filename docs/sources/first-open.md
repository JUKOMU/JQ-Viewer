# 3. 初次打开：应用首页与侧边栏

打开应用后，先从首页认识搜索入口，再打开侧边栏了解其他页面。下面介绍这些区域的用途，并给出第一次阅读的简短路线。

## 首页上有什么

应用首页显示 **JQ Viewer** 标题和搜索区域。

- **搜索框**：输入关键词或作品 ID，查找想看的作品。
- **单个解析、批量解析**：用于处理包含编号的文本。第一次使用可以先直接搜索，不必先启用解析模式。
- **搜索选项与帮助**：搜索区域提供选项入口；问号按钮可以查看应用内的简短说明。

搜索后会进入结果列表；输入纯数字作品 ID 时，也可以直接打开对应作品的详情。

搜索方式、筛选项和批量解析的完整说明，将在“首页搜索与分类”章展开。本章先认识入口。

## 打开侧边栏

侧边栏的显示方式随**窗口宽度**变化：

- **手机或较窄窗口**：点击页面左上角的菜单按钮打开侧边栏。选择入口后进入相应页面；点击侧边栏外的遮罩可以收起菜单。
- **较宽窗口**：侧边栏显示在页面左侧，可以用展开或收起按钮切换完整菜单与紧凑显示。

桌面端缩窄窗口后，也会使用菜单按钮。因此，找不到左上角按钮时，先看左侧是否已经显示侧边栏。

## 侧边栏中的主要入口

主要入口按应用中的顺序列出：

| 入口 | 展示什么、可以做什么 |
| --- | --- |
| **首页** | 回到搜索入口，开始新的关键词搜索或编号解析 |
| **分类** | 查看分类，按分类及筛选条件查找作品 |
| **收藏夹** | 查看和管理在线、离线收藏夹，整理收藏并进行相关批量操作 |
| **下载** | 查看下载内容和任务，进入阅读、导出及本地文件管理等操作 |
| **历史** | 查看浏览历史与解析历史，从记录返回相应内容 |
| **设置** | 调整阅读、下载、缓存和导出等设置，进入网络状态、用户、日志和关于等页面 |

其中，“下载”页有 **“下载”** 和 **“导出”** 两个视图，并非只有已下载作品的列表；下载或导出任务进行时，侧边栏的下载入口还可能显示进度。

“设置”下的页面也各有用途。例如 **“食用方法”** 是导出模板的使用帮助，用来解释规则和示例；实际发起导出仍在相关操作页面完成。各页面的详细说明会放在对应章节。

## 侧边栏上方：账号与联网状态

侧边栏上方除了头像和账号信息，还有在线／离线状态按钮。它们分别表示账号状态与应用的在线访问状态。

**账号区域**

这里会显示账号信息，或“未登录”“正在登录”“登录失败，点击重试”等状态。点击账号区域可以查看账号相关信息或按提示登录、重试；也可以从 **“设置 → 用户”** 进入用户页面。

如果保留了先前的头像或用户名，应同时查看旁边的状态文字，确认当前是否已登录成功。需要使用在线收藏等账号功能时，再完成相应登录。

**在线／离线按钮**

| 状态 | 点击后的用途 |
| --- | --- |
| 在线 | 可以手动切换为离线模式 |
| 离线 | 尝试检测并恢复在线访问 |
| 正在恢复、恢复失败 | 等待结果，或按失败提示再次尝试 |

未登录与离线不是同一个状态。搜索和网络图片阅读需要网络及可用的在线访问；使用这些入口不要求先完成账号登录。

离线收藏夹用于保存收藏记录，离线阅读则需要本地可用的图片或文件。收藏了作品，不代表章节图片已经下载完成。

## 第一次阅读可以这样走

先从最简单的在线搜索开始：

1. 在首页搜索框输入一个关键词，执行搜索。
2. 在搜索结果中打开一部作品，进入详情页。
3. 打开 **“章节”**，选择想看的章节。
4. 点击上方的 **“开始阅读”**，进入阅读器。

这条路线对应“首页搜索 → 作品详情 → 选择章节 → 阅读”。选中章节和点击“开始阅读”是两个动作。

阅读器的翻页、工具栏、阅读来源和设置，以及 Android 触控与桌面键鼠操作的差异，会在“作品详情与阅读”章详细介绍。现在先认识应用入口和页面之间的关系。
