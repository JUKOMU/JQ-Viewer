# 8. 历史

从主侧边栏进入“历史”，可以找回之前打开过的作品，或再次使用提交过的解析文本。

本章的常用路线是：先判断要找的是作品还是一段文本，再切换到对应标签；找到后打开、复制，或选择需要清理的记录。

<a id="history-page"></a>

## 8.1 认识历史页

页面顶部提供两个标签：

| 标签 | 记录什么 | 点击记录后做什么 |
| --- | --- | --- |
| 浏览历史 | 打开作品详情、进入相关阅读器时保存的作品与章节信息 | 进入该作品的详情页；记录中带有章节信息时，尝试选中对应章节 |
| 解析历史 | 通过“单个解析”或“批量解析”提交的文本及解析模式 | 按该模式再次使用保存的文本 |

进入页面时默认显示“浏览历史”。各标签上方显示记录总数，并提供“清空”和“多选”。

这些记录保存在当前设备的应用数据中，不是收藏夹，也不能当作跨设备同步的作品列表。要长期整理作品，见[“收藏夹”一章](favorites.md)。

### 与搜索提示、阅读进度的区别

使用过程中还会遇到另外两类数据：

- **搜索框的历史提示**：在支持历史提示的输入框中显示以前输入的关键词，方便再次填入或搜索。它与本页的“解析历史”分开保存，普通关键词搜索也不等于提交了解析记录。
- **阅读进度**：记录某个作品章节或本地文件读到了哪里，供阅读器恢复位置。历史卡片中的章节和访问时间不能代表完整的阅读进度。

因此，删除本页的一条历史，不会同时清除搜索框中的同名提示，也不会把相关阅读器统一重置到第一页。具体清理范围见 [8.5](#clear-history)。

<a id="browse-history"></a>

## 8.2 查找浏览记录并返回作品

### 按时间找到作品

“浏览历史”按时间分组，组内较近的记录排在前面。分组依次为：

**今天、昨天、本周、本月、3个月内、6个月内、今年、更早。**

页面只显示有记录的分组。分组按设备的本地日期和时区计算，“本周”从周一开始；同一条记录只会归入其中一个组，不会在“今天”“本周”“本月”中重复列出。

1. 先根据大致访问时间找到分组，点击组标题展开或收起。
2. 对照作品封面、标题、ID 和作者识别条目；有章节信息时，卡片还会显示章节名称。
3. 继续向下滚动，页面会加载更多记录。组标题的数量是该组的记录总数，可能多于当前已经显示的卡片。

卡片时间会按距离当前的长短显示为“刚刚”“几分钟前”等，较早的记录显示具体日期。

**当前历史页没有关键词搜索框，也没有按作者、作品 ID 或日期筛选的入口。** 如果已经记得作品 ID，可以直接使用首页的搜索或解析入口；需要按关键词搜索作品时，见[“搜索与分类”一章](search-and-categories.md)。

收起分组只改变列表显示，不会删除记录，也不会把该组排除在“全选”之外。

### 从记录返回详情与阅读

退出多选后，点击浏览卡片即可进入作品详情；也可以点击卡片的操作菜单，选择“进入详情页”。

如果记录带有章节 ID，详情页会尝试选中相应章节。之后按详情页当前提供的阅读入口继续阅读，位置恢复遵循阅读器保存的进度。

**这一步会先打开详情页，不会直接跳到历史访问时的某一页。** 如果作品内容或章节信息已经变化，以当前详情页实际显示的内容为准。

已经下载的章节、已经导出或导入的 PDF、CBZ，仍可从“下载”页找到。即使某次本地阅读生成了浏览记录，点击该历史卡片也会打开作品详情，不能将它当作本地文件的直接打开入口。离线阅读和查找本地文件的步骤见[“下载”一章](downloads.md)。

能看到保存的历史卡片，也不代表作品详情或重新解析的内容一定能离线取得。

### 为什么有记录，不一定代表读过正文

打开作品详情也可以生成浏览记录，不需要先把作品读完；进入阅读器后，相关章节信息还可能更新。

连续访问同一作品时，最近一条记录可以被更新；访问过其他作品后再回来，同一作品可能再次出现。例如先打开作品 A，再打开 B，之后回到 A，列表中可能有两条 A。

页面上的“共 N 条记录”统计历史条目，不是独立作品数量，也不是翻页次数。需要删除重复访问条目时，可以使用单条删除或多选整理。

## 8.3 查看和重新使用解析记录

切换到“解析历史”，可以看到保存的文本、时间，以及“单个解析”或“批量解析”标记。较近的记录排在前面，向下滚动会继续加载。

这些记录用于重新使用输入文本。提交文本时就可能生成记录，所以列表中出现一条解析历史，并不能证明当时已成功取得作品。

### 单个解析记录

点击标为“单个解析”的记录，应用会提取保存文本中的数字，再进入搜索／解析流程。

它会重新处理文本，不保存上一次解析出的页面。如果文本包含多段数字，数字会合并后用于此次查询；结果不符合预期时，可以先复制文本，到首页核对并改成正确的作品 ID。输入规则见[“搜索与分类”一章](search-and-categories.md)。

### 批量解析记录

点击标为“批量解析”的记录，会将保存的原始文本带入批量解析页，再次进行解析。

历史中保存的是提交的文本，不是上一次结果列表的快照。之前在批量解析页移除的条目、筛选后的结果等，不会因此成为这条历史的新内容。需要调整输入或处理解析结果时，使用批量解析页当前提供的操作。

### 复制文本后修改

历史列表本身不提供文本编辑：

1. 打开解析卡片的操作菜单，选择“复制文本”。
2. 到需要使用的位置粘贴，确认取得的是完整文本。
3. 修改后，再按需要选择单个解析或批量解析。

复制操作依赖设备上的剪贴板能力，当前操作不一定显示成功提示。需要确认是否复制成功时，以实际粘贴出的内容为准。

相同文本再次提交时，会更新为较近的一条解析记录；同一段文本换用另一种解析模式后，列表以最近一次保存的模式为准。记录排序和模式变化不一定意味着丢失了其他解析结果，因为这里保存的并非结果归档。

## 8.4 删除单条记录与批量整理

### 删除一条记录

在浏览历史或解析历史中，打开目标卡片的操作菜单，选择“删除此记录”，再核对确认框并选择“删除”。选择“取消”则保留记录。

删除的是本次选中的历史条目。同一作品的其他访问条目可能仍在，搜索框提示、收藏和下载内容也分别保留。

历史没有撤销删除或回收站入口，确认前先核对作品或文本。

### 进入多选

可以通过以下方式进入当前标签的多选：

- 点击列表上方的“多选”。
- 长按目标卡片；桌面端也可以按住鼠标主键操作。
- 打开卡片操作菜单，选择“多选”。

进入多选后，点击卡片用于选中或取消选中，不再打开详情或重新解析。需要切换“浏览历史／解析历史”时，先退出多选。

### 全选与反选覆盖哪些记录

多选状态提供已选数量、“全选”“反选”和“取消”，底部提供“删除”。

| 操作 | 实际范围 |
| --- | --- |
| 点击卡片 | 切换这一条记录的选中状态 |
| 全选 | 选中当前标签下的全部记录，包括尚未滚动加载的条目；浏览历史还包括折叠分组 |
| 反选 | 在当前标签下的全部记录中，将已选与未选状态对调，范围同“全选” |
| 取消 | 退出多选并清除本次选择，保留历史记录 |

**“全选”不是只选屏幕上可见的记录，也不是只选展开的时间组。** 浏览历史和解析历史分别处理，选择一个标签不会同时选中另一个标签的记录。

记录较多时，全选或反选需要先读取完整列表。若提示“读取完整历史失败，本次选择未生效”，不要按预期数量直接执行删除，先检查实际选中数量。

### 执行批量删除

1. 选好记录后，查看已选数量，点击底部“删除”。
2. 确认框会注明删除的是浏览记录还是解析记录，以及条数；核对后确认。
3. 等待删除结束，查看成功、失败条数，再检查列表中的剩余记录。

如果只想整理某个时间段，可以展开相应浏览分组，逐条选中要删除的卡片。当前页面没有“只全选这个分组”的操作。

## 8.5 清空历史及其影响

要清理某一类全部历史，在相应标签中点击“清空”，再阅读确认框并确认。取消则不执行清空。

- 在“浏览历史”中清空，处理该标签的全部浏览记录，包括所有时间分组。
- 在“解析历史”中清空，处理该标签的全部解析记录。

两个标签分别清空。清空其中一个，不会自动清空另一个。清空无法撤销，想只保留或移除部分条目时，先使用多选。

### 删除、清空与其他数据的关系

| 数据 | 删除／清空本页历史后的影响 |
| --- | --- |
| 本次操作选中的浏览或解析记录 | 删除；清空操作针对当前标签的全部记录 |
| 另一个历史标签中的记录 | 保留，需要到对应标签单独处理 |
| 搜索框的历史提示 | 保留，在支持历史提示的输入框中另外清除 |
| 已保存的阅读位置 | 保留，阅读器再次打开相关内容时仍可能恢复位置 |
| 收藏夹、下载图片、本地 PDF／CBZ、导出任务记录 | 保留，仍由各自页面管理 |

清空历史主要用于整理记录，不能用来释放下载图片和导出文件占用的空间。需要管理实际文件时，见[“下载”一章](downloads.md)；缓存相关操作见[图片缓存](settings/cache.md)。

历史被删除后，再次打开作品详情或提交解析文本，仍可能形成新的记录。这与清理前保留下来的旧条目需要区分。

### 清理搜索框的历史提示

如果清空历史页后，输入框仍提示以前搜索过的关键词，先回到对应搜索入口，打开历史提示列表，使用其中的“清除”。

输入框提示按使用场景分别保存。某个输入框里的“清除”针对该场景的搜索提示，不等于清空历史页，也不等于清除所有搜索入口的提示。当前搜索提示的“清除”会直接执行，不会另弹一个清空确认框。

## 8.6 遇到问题时

### 记得看过作品，但列表里找不到

先确认位于“浏览历史”，展开大致访问时间对应的分组，并继续滚动加载。作品标题记不清时，可以对照封面、作者和 ID；分组按照当前设备日期计算，设备日期变化也会影响分组位置。

浏览历史依赖阅读入口所提供的作品信息。没有关联作品信息的本地文件，不应预期一定能在这里找回；到“下载 → 导出 → 文件”查找已登记的本地文件。

列表为空时，也要区分确实没有记录、已经清理和读取失败。出现“浏览历史加载失败”或分组中的加载失败提示时，使用提示中的“重试”；解析历史若显示异常，可退出后重新进入，核对是否恢复。

### 点击记录后没有回到上次那一页

浏览记录会先进入作品详情，带有章节信息时尝试选择对应章节；具体页码由阅读器另外保存。先确认进入了相同作品、章节或本地文件，再看阅读器恢复的位置。完整阅读操作见[“作品详情与阅读”一章](reading.md)。

如果此前读的是本地 PDF 或 CBZ，应从文件列表打开相应文件，不能用历史卡片进入作品详情代替这一步。

### 解析历史还在，但再次打开失败

历史保留了输入文本，不保证作品仍可取得，也不代表当时解析成功。先检查当前联网状态、解析模式和文本中的 ID；有疑问时复制原文，核对后重新提交。

解析模式和批量结果处理见[“搜索与分类”一章](search-and-categories.md)；线路与网络状态入口见[网络状态与线路选择](settings/network.md)。

### 删除后为什么还有同名内容或阅读位置

先辨认剩下的是什么：同一作品的另一条访问历史、另一个历史标签、搜索框提示、收藏内容，还是阅读器保存的位置。它们可能显示相同作品名称，但清理入口和作用不同。

批量删除后若有失败条数，先核对剩余记录。需要确认单条删除或清空结果时，可以退出历史页后重新进入检查；之后发生的新访问或新解析也会生成记录。
