# 1. 项目介绍

JQ Viewer 是一款 JMComic 第三方漫画阅读器，支持 Android 移动端，以及 Windows、Linux 桌面端。你可以在同一套界面中搜索作品、阅读章节、整理收藏和管理下载，也可以使用本地文件阅读。

## 主要功能

| 想做的事 | 应用提供的能力 |
| --- | --- |
| 查找作品 | 关键词与作品 ID 搜索、分类浏览，以及排序和筛选 |
| 阅读漫画 | 查看作品详情、选择章节，使用纵向滚动或横向翻页阅读 |
| 整理内容 | 在线或离线收藏夹、浏览历史、解析历史，以及相关批量操作 |
| 保存到本地 | 下载章节供离线阅读，导入本地 PDF、CBZ 文件，并按需要导出文件 |
| 处理一批编号 | 从文本中解析作品 ID，进行后续查找、收藏或下载 |

移动端和桌面端共用主要页面。触控与键鼠操作、文件位置和系统授权存在差异，相关章节会在使用到的位置分别说明。

## 支持的平台

| 平台 | 支持范围 |
| --- | --- |
| Android | Android 7.0 及以上 |
| Windows | x64；Windows on ARM 使用 x64 包，需要系统提供 x64 应用仿真 |
| Linux | x64、arm64 |

## 从哪里开始

- **还没有安装**：先阅读[下载、安装与更新](installation.md)，选择适合设备的发行包。
- **已经安装，第一次使用**：阅读[应用首页与侧边栏](first-open.md)，认识主界面和常用入口。
- **希望查阅某项功能**：后续章节按应用页面与相关功能组织，包括首页搜索与分类、作品详情与阅读、收藏夹、下载、历史、设置，以及常见问题。
