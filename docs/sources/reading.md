# 5. 作品详情与阅读

从搜索、分类或收藏等页面点击作品，可以进入详情页。在这里可以了解作品信息、选择章节、查看预览和评论，再进入阅读器。

本章先介绍详情页和章节操作，再说明阅读来源、阅读器控制与设置。通过下载页直接打开本地内容的入口，见[“下载”一章](downloads.md)；本章说明进入阅读器后的操作。

<a id="detail-page"></a>

## 5.1 认识作品详情页

详情页上方显示封面、标题、作者、描述，以及当前章节的页数。章节信息加载完成后，页数会随当前选中章节变化。

点击封面可以打开封面预览，轻点预览区域可以关闭。触控设备支持双指缩放和双击调整缩放；放大后可以拖动查看其他位置。

“开始阅读”按钮用于打开当前选中章节。旁边的竖向省略号用于选择阅读来源，具体见本章“选择阅读来源”。

下方分为四个标签页：

| 标签页 | 展示什么、能做什么 |
| --- | --- |
| 本子信息 | 查看 ID、标题、描述、作者、标签、登场人物、分类等信息，以及点赞、收藏和下载入口 |
| 章节 | 查看章节列表、选择当前章节，并选择要下载的章节 |
| 预览 | 查看当前章节的缩略图，从指定页进入阅读器 |
| 评论 | 查看评论、回复及已有点赞数，继续加载更多评论 |

点击标签名称即可切换。在触控设备上，也可以横向滑动标签内容区域切换。

“本子信息”中，带复制图标的字段可以点击复制；较长描述可以展开或收起。点击作者、标签、登场人物或作品名称标签，可以用该文字进入搜索结果页；下方的相关作品卡片可以打开另一部作品的详情。

<a id="choose-chapter"></a>

## 5.2 选择章节并开始阅读

多章节作品建议先确认当前章节：

1. 打开详情页中的“章节”。
2. 找到想阅读的章节，点击它，使其成为当前选中章节。
3. 如需先确认内容，切换到“预览”。
4. 点击页面上方“开始阅读”，打开当前选中章节。

选择章节本身不会立即打开阅读器。当前章节会影响详情页的页数、预览、单章下载和阅读来源。

章节区域可以用工具栏中的图标切换列表与网格。网格模式下，再次点击已选中的章节，可以展开该章节的下载操作按钮；点击其中的返回箭头可收起操作。

章节旁的图片、CBZ、PDF 标记表示应用识别到的本地来源。其中图片标记对应已完成的图片下载，CBZ、PDF 标记对应已登记并关联到该章节的本地文件。文件的导入和管理见[“下载”一章](downloads.md)。

通过带有章节信息的入口返回详情页时，页面可能已经选中相应章节；继续操作前，以章节区域的当前选中项为准。

<a id="detail-actions"></a>

## 5.3 收藏、点赞与下载

### 收藏与点赞

“本子信息”中的“收藏”用于保存作品条目。未收藏状态下点击它，会打开收藏夹选择窗口：

1. 选择在线或离线收藏来源。
2. 选择目标收藏夹；需要时可以在窗口中新建收藏夹。
3. 等待收藏结果提示。

未登录时，窗口只提供离线收藏来源；在线收藏需要登录账号。收藏保存的是作品条目，不会同时下载漫画图片。

详情页处于已收藏状态时，再次点击收藏按钮会请求取消在线收藏。离线条目的移除和整理请到“收藏夹”页完成；核对某个来源中是否已经保存，也应到相应收藏夹查看。

“点赞”需要先登录。点击后的状态以应用返回的结果为准；服务不支持取消点赞时，应用会给出提示。

### 下载当前章节

先在“章节”中选好目标，再回到“本子信息”点击“下载”。任务成功提交后，可以从侧边栏进入“下载”查看进度。

下载按钮会根据当前章节的任务状态显示不同文字：

| 显示文字 | 含义 |
| --- | --- |
| 下载 | 当前章节还没有对应任务，可以提交下载 |
| 队列中、下载中 | 任务已经创建，等待执行或正在执行 |
| 已暂停 | 对应任务处于暂停状态，请到下载页管理 |
| 已下载 | 对应章节的图片下载任务已经完成 |
| 重试 | 对应任务失败，可以重新提交 |

此处的下载操作只处理当前章节。队列管理、暂停、继续、删除和文件导出，见[“下载”一章](downloads.md)。

### 一次下载多个章节

1. 在“章节”区域点击“批量下载”，进入选择模式。
2. 点击要下载的章节，或使用“全选”“反选”。
3. 核对“开始下载”按钮中的已选数量。
4. 点击“开始下载”，逐项提交任务。
5. 到“下载”页查看任务进度。

已经排队、下载中、暂停或下载完成的章节不会被重复勾选；失败的章节可以重新选择。

选择模式中的“取消”用于清空本次勾选，右侧关闭图标用于退出选择模式。点击“开始下载”后，也会退出选择模式。

“已加入下载队列”或“已加入若干个下载任务”表示提交成功，不等于所有章节已经完成下载。

## 5.4 查看预览与评论

### 预览当前章节

“预览”显示当前选中章节的缩略图，每张图附有页码。点击已经加载的缩略图，可以从对应页打开阅读器。

预览会分批加载。点击底部“查看更多图片”后，可以继续向下浏览，接近底部时会加载后续图片；如果提示有缺失图片，可以按页面提示重新加载。

需要预览其他章节时，先到“章节”选择目标，再返回“预览”。预览使用当前可用的章节来源，因此已经登记的本地内容也可以成为预览来源。

### 浏览评论

“评论”显示内容服务返回的评论、作者、时间、已有点赞数，以及回复内容。向下滚动接近底部时，会继续加载后续评论。

此区域用于浏览评论；当前正式版没有在这里提供发布评论、回复或给评论点赞的输入与操作入口。读取评论需要能连接内容服务。

<a id="reading-sources"></a>

## 5.5 选择阅读来源

“开始阅读”右侧的竖向省略号可以展开来源按钮。来源对应**当前选中的章节**，可用性会随章节变化。

| 来源 | 用途与前提 |
| --- | --- |
| 本地图片阅读 | 使用当前章节已完成下载的图片 |
| CBZ 阅读 | 使用应用已登记、关联到当前章节且可以读取的 CBZ 文件 |
| PDF 阅读 | 使用应用已登记、关联到当前章节且可以读取的 PDF 文件 |
| 网络图片阅读 | 进入图片阅读器；没有可用的已下载图片时，从内容服务获取章节和图片 |

本地图片、CBZ、PDF 来源不可用时，对应按钮不可点击。文件只是存放在设备上，并不一定已经登记或关联到当前章节；如何导入并检查本地文件，见[“下载”一章](downloads.md)。

### “开始阅读”会选哪个来源

点击“开始阅读”时，应用按当前识别到的来源优先选择：

1. 已完成的图片下载。
2. CBZ。
3. PDF。
4. 网络图片。

如果想使用其他来源，可以展开来源按钮手动选择。已登记的文件失效、不可读取或校验未通过时，应用可能提示该来源不可用，需要检查本地文件或改选其他可用来源。

图片阅读器本身会优先尝试已下载的章节图片。因此，“网络图片阅读”入口不表示强制忽略已有下载、重新从网络获取所有图片。

### 离线阅读从哪里进入

已经准备好的本地内容，可以从“下载”页打开，再按需要选择章节或文件。在线详情页、评论以及尚未下载的章节仍需要联网；准备离线阅读时，应先确认相应章节已经完成下载，或对应文件可以读取。

## 5.6 阅读器操作

进入阅读器后，上方工具栏显示返回按钮和标题，下方显示当前页、总页数、进度条及阅读设置入口。有章节信息的图片阅读器还会显示章节切换区域。

轻点阅读区域可以显示或隐藏工具栏：纵向模式点击内容区域；横向模式点击中间区域，左右边缘用于翻页。

### 纵向与横向

点击下方齿轮打开“阅读设置”，在“显示模式”中选择：

- **纵向**：将图片按顺序上下排列，通过上下滚动阅读。
- **横向**：以单页形式左右翻页，通过滑动或点击左右边缘切换图片。

切换模式时，阅读器会保留当前页的位置。触控设备可以在阅读区域双指缩放；双击可调整缩放，放大后拖动查看图片的其他部分。

放大状态下，拖动主要用于移动图片。需要继续翻页时，可以使用左右边缘或进度条；也可以先恢复缩放，再继续滑动。

### Android 触控操作

| 想做什么 | 操作 |
| --- | --- |
| 纵向继续阅读 | 向上滑动内容；向下滑动返回前面的内容 |
| 横向下一页／上一页 | 向左／向右滑动，或点击右侧／左侧边缘 |
| 显示或隐藏工具栏 | 纵向轻点内容区域；横向轻点中间区域 |
| 缩放与移动图片 | 双指缩放或双击，放大后拖动 |
| 用音量键阅读 | 先在阅读设置中开启“音量键翻页”；音量加向上滚动或到上一页，音量减向下滚动或到下一页 |

音量键在纵向模式中按一定距离滚动，在横向模式中切换上一页或下一页。

Android 阅读器隐藏工具栏时会进入阅读全屏，显示工具栏时退出相应全屏状态。屏幕方向、亮度和防止熄屏可以在阅读设置中调整。

### Windows、Linux 键鼠操作

| 想做什么 | 操作 |
| --- | --- |
| 纵向滚动 | 鼠标滚轮，或按住鼠标左键上下拖动 |
| 横向翻页 | 点击图片区域左侧／右侧，或按住鼠标左键左右拖动 |
| 上一页／下一页 | 方向键 ←／→；横向模式下 ↑／↓ 也可以逐页切换 |
| 纵向按距离滚动 | 方向键 ↑／↓ |
| 放大、缩小或恢复 | 顶部工具栏的“放大”“缩小”“重置缩放”按钮 |
| 进入或退出页面全屏 | 顶部工具栏的全屏按钮；是否可用取决于当前运行环境 |

方向键用于阅读区域获得键盘操作时；在设置输入框、按钮或进度条等控件上操作时，按键优先交给当前控件。需要继续用方向键阅读时，可以点击阅读区域。

桌面端还可以在阅读设置中调整默认宽度。横向模式下，如果按所选宽度显示后的图片高于窗口，可以用滚轮或上下拖动查看图片的上下部分。

## 5.7 阅读进度与切换章节

### 跳到某一页

显示底部工具栏后，拖动进度条到目标位置即可跳页。进度条两侧显示当前页和总页数。

从详情页的预览缩略图进入时，会优先打开所点的页码。没有指定页码时，应用会尝试恢复该章节已经记录的阅读位置；没有记录则从第 1 页开始。

### 切换章节

网络图片与已下载图片使用的阅读器，在有章节信息时提供：

- **上一章／下一章**：打开相邻章节；没有相邻章节时对应按钮不可用。
- **当前章节名称**：点击展开章节列表，再选择目标章节。

阅读器切换章节后，会尝试恢复目标章节的阅读位置。图片阅读器会先尝试目标章节的已下载图片，没有可用下载时再联网读取；不会自动改为该章节的 CBZ 或 PDF 文件。

使用 PDF 或 CBZ 阅读器时，当前正式版不显示这组章节切换按钮。需要换章或换来源，请点击顶部返回按钮，回到详情页或本地内容的选择页面后操作。

图片阅读器到达章节末尾时，可以根据设置自动展开工具栏，再由你选择是否进入下一章。

### 章节进度与文件进度

同一部作品、同一章节的阅读位置按章节记录，切换相应来源后可以继续使用该章节的进度。

从本地文件列表直接打开整份 PDF 或 CBZ 时，则按该文件记录阅读位置。文件中即使包含多个章节，整份文件的第几页也可能与某一章节内的第几页不同。

阅读位置保存在当前设备的应用数据中。浏览历史用于找回访问过的作品和章节，具体入口与管理见[“历史”一章](history.md)。

## 5.8 调整阅读设置

点击底部工具栏左侧的齿轮打开“阅读设置”。点击面板右上角关闭图标，或点击面板外的遮罩区域，可以返回阅读。

### 显示、方向与亮度

| 设置 | 作用与适用范围 |
| --- | --- |
| 显示模式 | 选择纵向滚动或横向翻页 |
| 默认宽度 | 桌面端调整图片相对阅读区域的宽度；可重置为自动适配 |
| 屏幕方向 | Android 选择自动、竖屏或横屏；桌面端不提供应用级屏幕方向控制 |
| 亮度 | Android 可以选择跟随系统，关闭跟随系统后手动调节阅读亮度；桌面端不提供系统亮度调节 |
| 防止熄屏 | 阅读期间保持屏幕常亮；桌面端是否可用取决于运行环境 |
| 音量键翻页 | Android 可用，按当前阅读模式执行滚动或翻页；桌面端使用方向键 |
| 阅读结束时展开工具栏 | 图片阅读器纵向到底或横向到达最后一页时，自动显示工具栏 |

桌面端的默认宽度可以调为 0%，这会隐藏图片。如果阅读区域没有显示图片而进度仍正常，可以先点击“重置为自动适配”。

“显示模式”的纵向／横向控制图片如何排列；“屏幕方向”的竖屏／横屏控制设备显示方向，可以分别选择。

面板中的“页面全屏”和“阅读器宿主状态”用于显示当前环境的能力与接入情况，不是额外的开关。不支持的选项会禁用并显示原因。

### 预加载设置

| 设置 | 作用 | 范围与生效时机 |
| --- | --- | --- |
| 预加载页数 | 控制阅读时前后预先准备的图片页数 | 5—50 页，保存后下次阅读生效 |
| 预加载并发数 | 控制图片预加载同时执行的任务数 | 1—12，保存后需要重启应用进程 |

调大预加载范围或并发数不一定能解决网络错误；可以先使用当前设置，根据设备和连接情况再调整。设置保存结果以应用提示为准。

阅读设置会被应用记住，下一次进入阅读时继续使用。应用“设置”页中与阅读有关的配置，集中见[阅读设置](settings.md#reader-settings)。

## 5.9 遇到问题时

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 点了章节却没有开始阅读 | 章节点击用于选择；再点击顶部“开始阅读”，或在预览中点击目标页 |
| 预览或下载的内容不是想要的章节 | 回到“章节”确认当前选中项，再执行预览或下载 |
| 本地图片、CBZ 或 PDF 来源按钮不可点击 | 当前章节没有对应可用来源；检查下载是否完成、文件是否已登记并关联 |
| 离线时详情或评论无法加载 | 从下载页打开已经准备好的本地内容；在线信息仍需要连接内容服务 |
| 阅读时看不到工具栏 | 纵向轻点内容区域，横向轻点中间区域 |
| 网络／已下载图片阅读时出现“图片加载失败” | 恢复与内容服务的连接后，点击失败区域的重试按钮；它会处理本章已标记失败的图片 |
| PDF／CBZ 页面读取失败 | 返回本地内容页面检查文件是否仍可访问；当前文件阅读器不提供图片阅读器的失败图片重试按钮 |
| 使用 PDF／CBZ 时找不到上一章、下一章 | 返回详情页或本地内容选择页面，再选章节；当前正式版文件阅读器没有这组按钮 |
| 桌面端方向键没有翻页 | 先点击阅读区域，检查焦点是否还停留在输入框、进度条或其他控件上 |
| 桌面端图片不见了，但页码仍在 | 检查默认宽度是否为 0%，重置为自动适配 |
| 改了预加载并发数，表现没有变化 | 该设置需要重启应用进程后生效 |
