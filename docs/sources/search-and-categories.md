# 4. 首页搜索与分类

打开应用后，可以直接使用首页的搜索区域查找作品，也可以从侧边栏进入“分类”，按内容类别浏览。

如果手中已经有作品编号，首页还提供单个解析和批量解析入口，用来处理纯数字编号，或从一段文本中提取编号。

| 现在手中有什么 | 从哪里开始 |
| --- | --- |
| 作品名称、作者、标签等关键词 | 首页输入关键词，按需要选择搜索方式 |
| 一个纯数字作品 ID | 首页直接输入 ID 并搜索 |
| 一段只包含一个作品编号的文字 | 首页选择“单个解析” |
| 多个编号、编号清单或包含编号的图片 | 首页选择“批量解析” |
| 没有明确关键词，想按类型浏览 | 侧边栏 → 分类 |

搜索、分类以及解析后获取作品信息都需要正常连接内容服务。在线收藏还需要登录账号；离线收藏的用途和管理方式见[“收藏夹”一章](favorites.md)。

## 4.1 从首页搜索作品

### 输入关键词

1. 从侧边栏打开“首页”。
2. 在“请输入关键词”输入框中填写作品名称、作者或其他关键词。普通关键词搜索时，让“单个解析”和“批量解析”保持未选中；再次点击已选中的模式按钮即可取消该模式。
3. 如需调整范围，展开“更多选项”。
4. 点击输入框右侧的放大镜按钮开始搜索；使用键盘时，也可以按 Enter 提交单行输入。

搜索后进入结果页。点击输入框可以查看已有的搜索历史，选择历史条目会将关键词填入输入框，再提交即可重新搜索。

### 调整搜索选项

“更多选项”中有三组选项：

| 选项 | 可选内容 | 用途 |
| --- | --- | --- |
| 排序 | 最新、最多观看、图片最多、最多喜欢 | 选择结果的排列方式 |
| 时间范围 | 全部时间、今日、本周、本月 | 选择查找的时间范围 |
| 搜索方式 | 站内搜索、作品、作者、标签、登场人物 | 选择关键词对应的查找方式 |

默认选项为“最新”“全部时间”“站内搜索”。例如，已经知道作者名称时，可以选择“作者”再搜索；按标签查找时，选择“标签”。

选项选好后，需要再次点击搜索按钮才会应用。结果页顶部也提供关键词与这些选项，修改后重新搜索会从第 1 页开始显示。

### 直接输入作品 ID

首页输入框中的内容如果全部是数字，应用会按作品 ID 查找，成功后直接打开作品详情。

这条路径适合已经知道编号的情况，不必先切换到“单个解析”。如果输入的是含文字或其他符号的编号说明，可以使用本章后面的单个解析功能。

## 4.2 浏览搜索结果

### 列表与网格

结果区域显示条目数量和当前加载的页码。可以使用上方的“列表”“网格”切换显示方式。

| 显示方式 | 适合怎样查看 |
| --- | --- |
| 列表 | 同时查看封面、标题、ID，以及服务返回的作者、标签等信息 |
| 网格 | 集中浏览封面和标题；可使用 2x—7x 按钮调整每行列数 |

应用会记住所选的网格列数。点击任一作品卡片可以打开详情页，后续如何查看章节、选择章节和阅读，见[“作品详情与阅读”一章](reading.md)。

卡片角落的序号表示它在结果中的排列位置。需要引用作品编号时，请查看列表中的“ID”，不要把排列序号当作作品 ID。

### 继续浏览和跳页

向下滚动接近已加载结果的末尾时，应用会继续加载下一页。结果区域的页码提示会反映当前已加载的页码范围。

如果想直接查看某一页，展开右下角的快捷操作按钮，选择“跳页”，输入提示范围内的页码，再点击“跳转”。

跳页后想看之前的页码，可以再次使用“跳页”。在触控设备上，如果已加载结果的起始页大于 1，也可以在页面顶部下拉，补载前一页。

快捷操作中还提供：

- **搜索**：打开搜索面板，方便在浏览到较下方时修改关键词和选项。
- **回顶**：回到页面顶部。
- **返回**：返回上一页面；没有可返回的页面时进入首页。

### 对单个结果执行操作

切换到列表显示后，点击卡片的“更多操作”（竖向省略号），可以选择“详情”“阅读”“下载”“收藏”或“多选”。

- **详情**：打开该作品的详情页。
- **阅读**：通过快捷入口获取章节并打开阅读器。需要自行选择章节时，先进入详情页。
- **下载**：获取章节并加入下载队列。这里按章节创建任务；多章节作品需要在详情页选择所需章节，不能把此入口理解为自动下载全本。
- **收藏**：打开收藏夹选择窗口，选择要保存到的收藏夹。
- **多选**：进入本页的批量选择状态。

收藏夹选择窗口在未登录时只提供离线收藏来源；登录后可以选择在线收藏来源。离线收藏保存作品条目信息，下载操作才会创建漫画文件下载任务。

下载任务的进度与文件管理见[“下载”一章](downloads.md)；收藏夹的在线、离线区别与整理方式见[“收藏夹”一章](favorites.md)。

### 选择多个结果

可以长按作品卡片进入多选；桌面端使用鼠标左键按住卡片也能进入。列表模式下，还可以从“更多操作”中选择“多选”。

进入多选后：

1. 点击需要处理的卡片以选中或取消选中。
2. 需要时使用“全选”或“反选”，并核对“已选择”数量。
3. 点击下方“收藏”或“下载”执行操作。
4. 点击“取消”退出多选。

这里的全选和反选以**已经加载的结果条目**为范围。多选期间不会继续加载新的结果页；需要选择更多条目时，先退出多选并加载所需结果，再重新选择。

批量下载会逐项提交章节任务。提交成功后，应到“下载”页查看实际下载进度；提交完成不等于文件已经下载完成。

## 4.3 从侧边栏进入分类

“分类”适合没有明确关键词、希望按内容类别浏览作品时使用。打开侧边栏中的“分类”后，页面上方显示分类、排序和时间范围选项，下方显示结果。

分类选项包括：同人、单本、短篇、其他、韩漫、美漫、cosplay 和 3D。

使用步骤：

1. 从侧边栏进入“分类”。
2. 选择一个分类，再按需要调整排序和时间范围。默认选项为“同人”“最新”“全部时间”。
3. 点击选项区域右下方的勾选图标按钮，提交本次选择。
4. 在下方浏览结果，点击作品进入详情。

初次进入分类页时，需要提交选择才会查询。只改变分类或排序选项不会立即刷新结果。

旁边的圆形箭头按钮用于重置选项。重置后仍需点击勾选图标按钮，才会按照默认选项重新查询。

分类结果与搜索结果使用相同的列表、网格、继续加载、跳页和多选操作。列表卡片的“更多操作”也可以用于阅读、收藏和下载。

分类结果右下角的快捷操作中，“搜索”用于打开分类选项面板；“返回”会清空当前分类结果，留在分类页继续选择。

## 4.4 单个解析：从文本中取出一个编号

单个解析适合手中的文本只对应一个作品编号，例如复制来的编号说明中包含文字和标点。

1. 回到首页，点击“单个解析”。
2. 输入或粘贴包含编号的文本。
3. 点击搜索按钮。应用会移除所有非数字字符，再按得到的数字查找作品。
4. 找到作品后，直接进入详情页。

例如，输入“编号：123456”会提取出“123456”。这里的数字仅用来演示整理规则，不代表可用作品。

**一段文本里有多组数字时，请使用批量解析。** 单个解析会把所有数字连在一起：例如“123456 / 234567”会变成“123456234567”，不会分别查找两个作品。

再次点击“单个解析”可以退出该模式，恢复普通关键词搜索。

## 4.5 批量解析：处理一组编号

批量解析把文本中的编号整理成作品列表，并提供原文核对、文本编辑、收藏状态对照和保存到收藏夹等操作。

### 从文本生成列表

1. 回到首页，点击“批量解析”。
2. 在多行输入框中粘贴编号清单，或包含编号的文字。
3. 点击右侧搜索按钮，进入批量解析页。
4. 等待应用逐项获取作品信息，核对原文和结果列表。

批量解析按以下规则处理输入：

- 每一段**连续的三位及以上数字**都作为一个候选 ID。同一行可以包含多个候选 ID。
- 一位或两位数字会被过滤。
- 重复 ID 只保留第一次出现的条目，结果按首次出现的顺序排列。
- 数字符合提取规则后，还需要能从内容服务查到作品信息，才会显示为结果卡片。

例如，以下文本：

~~~text
第一组：123456、234567
待看：345678
再记一次：123456
数量：12
~~~

会整理出“123456”“234567”“345678”三个候选 ID，重复的“123456”和两位数字“12”不会新增条目。这些数字只演示提取规则，不保证能查询到实际作品。

应用会提取所有符合位数要求的数字。因此，年份、三位以上的数量等也可能被当作候选 ID；混合文本较复杂时，可以使用下方的原文编辑工具先整理。

### 对照原文和结果

批量解析页上方保留输入原文，下方显示查询成功的作品卡片。可以用“展开原文”“收起原文”调整原文区域是否显示。

原文中会对可定位的编号、被过滤的短数字和查询失败的编号作标记。点击可定位的编号，会滚动到对应作品；浏览结果时，原文也会高亮对应位置，便于核对。

结果列表同样可以切换为列表或网格。顶部的条目统计按提取、去重后的候选 ID 计算，实际出现的作品卡片可能更少；没有结果的编号需要结合原文标记检查。

### 修改原文并重新解析

点击顶部的编辑图标，可以直接修改本次原文。编辑区域提供以下工具：

| 工具 | 作用 |
| --- | --- |
| 查找、替换为、全部替换 | 把原文中匹配的文字统一替换为指定内容 |
| 去除空格 | 移除每行中的空格和制表符，保留换行 |
| 按 ID 分行 | 按当前提取规则去重，只保留候选 ID，整理为每行一个编号 |
| 应用修改 | 使用编辑后的文本重新解析，更新作品列表 |

“按 ID 分行”会移除其他说明文字；“去除空格”可能把原本由空格分开的数字接起来。操作后可以先在编辑框里检查文本，再点击“应用修改”。

只点击编辑图标收起编辑区域，不会应用尚未提交的修改。

### 从图片识别编号

如果编号保存在图片中，可以在首页的批量解析模式下使用左侧“+”按钮：

1. 确认“设置 → 批量解析 → 图片 OCR 识别”已开启。
2. 在首页选择“批量解析”，点击输入框左侧的“+”。
3. 通过系统图片选择器或文件选择窗口选择图片。
4. 应用将识别出的文字追加到当前输入内容末尾，并自动进入批量解析。
5. 到批量解析页对照原文，发现数字识别有误时，使用编辑工具修改并应用。

Android 和桌面端均提供此入口，图片选择窗口由各自系统提供。OCR 的作用是从图片中识别文字，后续仍按同样的数字提取规则查询作品。

### 对照已有收藏并保存列表

展开原文后，可以开启“显示已收藏”，对照结果中哪些作品已经存在于在线收藏、离线收藏，或两者中都有。页面中的“双端收藏”指**在线和离线两种收藏来源中都有该作品**。

需要保留本次结果时：

1. 等待解析完成，核对作品列表。
2. 如果有不想保留的作品，切换到列表，在该卡片的“更多操作”中选择“从列表移除”。
3. 点击“保存当前列表到收藏夹”。
4. 在窗口中选择收藏来源和目标收藏夹。
5. 等待保存结果提示；如果提示部分失败，按提示核对对应条目。

保存操作以当前列表中查询成功且未移除的条目为范围，并会跳过已检测到的相应来源中的重复收藏。保存到离线收藏夹只保存条目信息，不会自动下载漫画文件。

“从列表移除”仅影响当前结果列表，不会删除已有收藏或下载，也不会改写原文；重新解析原文时，该编号仍可能再次出现。如果希望本次输入也去掉该编号，可在原文中编辑后应用修改。

批量解析的列表菜单还提供“详情”“阅读”“下载”“收藏”，用于处理单个作品。本页保存整份列表的入口是“保存当前列表到收藏夹”；普通搜索与分类结果页的多选操作见本章前文。

单个解析和批量解析提交的原始文本会记录在解析历史中，后续如何查阅和管理见[“历史”一章](history.md)。

## 4.6 遇到问题时

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 想按文字搜索，却进入了解析流程 | 检查首页是否选中了“单个解析”或“批量解析”；再次点击对应按钮退出模式 |
| 修改了搜索或分类选项，结果没有变化 | 选项变化后需要再次提交搜索；分类页点击勾选图标按钮 |
| ID 查询提示“本子不存在” | 检查编号及解析模式；该提示也可能出现在作品信息请求失败时，确认连接正常后再试 |
| 搜索结果显示错误卡片 | 检查应用与内容服务的连接；错误卡片提供“重试”按钮 |
| 批量解析提示“未发现有效 ID” | 输入中没有符合规则的连续三位及以上数字；检查 OCR 结果、空格和换行 |
| 批量解析只显示部分作品 | 对照原文中的失败标记，检查编号是否识别正确、作品是否可访问，再编辑原文并应用修改 |
| 批量解析的“+”按钮没有显示 | 先选择“批量解析”，再确认设置中的“图片 OCR 识别”已开启 |
| 批量下载已经提交，却还不能离线阅读 | 到“下载”页查看对应任务是否真正完成 |

首页搜索区域旁的问号按钮也提供单个解析、批量解析及搜索选项的简要帮助。
