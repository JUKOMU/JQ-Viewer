# 9. 设置与下级页面

从主侧边栏进入“设置”，可以调整阅读和下载偏好，管理导出位置与模板，也可以进入缓存、网络状态、用户、日志和关于页。

设置页既有可以直接修改的选项，也有通向其他页面的入口。阅读器中的设置面板用于阅读时的相关调整；不需要为了每次阅读都返回主设置页。

<a id="settings-overview"></a>

## 9.1 从设置页找到需要的选项

| --- | --- | --- |
| 图片缓存 | 查看用量、调整缓存上限、查看缓存图片、清空缓存 | [9.2](#image-cache) |
| 阅读设置 | 预加载、显示模式、默认宽度、设备支持的阅读能力 | [9.3](#reader-settings) |

| 批量解析 | 开启或关闭图片 OCR 识别入口 | [9.5](#ocr-settings) |
| 收藏夹导出设置 | 修改导出文本中每一行的格式 | [9.6](#favorite-export-format) |

| 诊断 → 应用日志 | 查看日志，选择并导出日志文件 | [9.11](#application-logs) |

页面没有统一的“保存全部”按钮。开关、分段按钮和输入框分别提交修改；修改输入框后，完成输入并离开该输入框，让页面处理变更。出现保存失败提示时，先核对当前值再继续操作。

其中两项需要特别注意：

- **预加载并发数、下载并发数**：保存后需要重启应用进程。只切换页面或返回首页不会使新的线程数生效。
- **下载位置相关开关**：会处理已有下载文件的搬迁，不只是改变下一次下载的保存位置。先阅读 [9.4](#download-settings) 对应平台的说明。

<a id="image-cache"></a>

## 9.2 图片缓存与缓存查看页

### 查看用量和设置上限

“图片缓存”中显示已用容量、实际容量和占用比例。“用户设置上限”允许输入 **64—1024 MB**。

用户设置的数值是请求的上限，实际可用容量还受设备资源限制。页面可能显示内存、磁盘缓存及容量收缩原因，因此“用户设置上限”和“实际”数值不一定相等。

Android 使用内存与磁盘图片缓存；桌面端的在线图片缓存位于应用进程内。两端都不能将缓存容量直接当作“已下载作品”占用，下载图片与导出文件另行管理。

调整上限后，核对页面返回的实际容量和用量。不需要为了阅读而预先填满缓存，也不能用缓存上限限制下载文件的总大小。

### 进入图片缓存查看页

点击“缓存用量”进入“图片缓存”页。这里按章节展示当前缓存图片：

1. 查看顶部容量、页数、章节数和大小汇总。
2. 点击章节组的汇总区域，展开或收起该组。
3. 查看页码，以及“原图”“缩略图”的缓存标记；点击图片可打开预览。
4. 需要查找所属作品时，点击章节 ID，进入对应作品详情。

标题需要另行获取。出现“标题获取失败”时，不等于组内已经存在的缓存图片也被删除。页面右上方可刷新；出现“缓存读取失败”时，可使用“重试”。

缓存会随着阅读、预加载和容量管理变化。这里是当前缓存的查看入口，不是完整下载列表，也不提供逐条删除缓存或导出缓存文件的操作。

### 清空缓存会影响什么

回到设置页，点击“清空缓存”，在确认框中确认；取消则保留。

该操作清理图片缓存，并清理本地 PDF 阅读产生的页面缓存。Android 的图片缓存清理同时涉及内存和磁盘缓存；桌面端涉及进程内图片缓存和 PDF 页面缓存。之后阅读相关内容时，可能需要重新取得图片或重新生成页面缓存。

**清空缓存不删除下载图片、PDF／CBZ 文件、收藏、历史记录或保存的阅读位置。** 想删除下载内容或本地文件时，使用“下载”页相应操作；想清理历史时，见[“历史”一章](history.md)。

## 9.3 阅读设置

### 预加载与显示模式

| 选项 | 作用与范围 | 生效说明 |
| --- | --- | --- |
| 预加载页数 | 阅读时前后预载图片的数量；可设为 5—50 页 | 保存后下次阅读生效 |
| 预加载并发数 | 同时预加载图片的线程数；可设为 1—12 | 应用进程重启后生效 |
| 显示模式 | 纵向或横向阅读 | 保存阅读偏好，阅读器中也提供相关调整 |
| 默认宽度 | 桌面端的阅读宽度偏好；可调整百分比，或“重置为自动适配” | Android 主设置页不显示这一项 |
| 阅读结束时展开工具栏 | 纵向读到底部，或横向进入最后一页时自动展开工具栏 | 可按使用习惯开启或关闭 |

显示模式中的“横向／纵向”控制阅读排列方式；下面的“屏幕方向”控制设备屏幕方向，两者是不同设置。

桌面端默认宽度的“自动适配”是独立状态。希望恢复自动计算时，使用“重置为自动适配”，不要用某个百分比代替。

预加载页数与下载并发也分别管理：前者服务于阅读时取图，后者用于下载任务。增加预加载范围不会把作品登记为已完成下载。

### 设备支持的阅读能力

设置页会根据当前运行环境显示可用状态，无法使用的选项会禁用并解释原因。

| 能力 | Android | 桌面端 |
| --- | --- | --- |
| 屏幕方向 | 自动、竖屏、横屏 | 不支持应用级屏幕方向控制 |
| 跟随系统亮度／手动亮度 | 关闭“跟随系统亮度”后可调阅读亮度 | 不支持从应用调节系统屏幕亮度 |
| 防止熄屏 | 阅读时保持屏幕常亮 | 依赖当前环境是否支持屏幕常亮能力 |
| 音量键翻页 | 横向模式翻页，纵向模式滚动 | 不支持可靠拦截系统音量键 |
| 页面全屏 | 由阅读器与平台能力配合处理 | 依赖当前环境是否支持页面全屏 |
| 阅读器宿主状态 | 阅读器进入、退出时处理宿主状态 | 支持时在离开阅读页后恢复相关状态 |

“页面全屏”和“阅读器宿主状态”在主设置页显示的是能力状态，不是需要手动开启的普通开关。桌面端某项显示“不可用”时，应以旁边的原因说明为准，不需要反复点击被禁用的选项。

本节说明主设置页中的偏好与能力，具体如何翻页、调出工具栏、调整阅读器内设置，以及 PDF／CBZ 的操作差异，见[“作品详情与阅读”一章](reading.md)。

## 9.4 下载并发与下载位置

### 下载并发数

“下载并发数”控制章节下载时同时进行的图片线程数，允许 **1—12**。保存后需要重启应用进程，新设置才生效。

它与“预加载并发数”独立：调整下载并发，不会同步修改阅读取图的线程数。

### Android：公开下载内容

Android 显示“公开下载内容”。开启后，下载图片使用公开位置，使系统相册可以查看；关闭后使用仅应用内可见的位置。

切换过程会搬迁已有下载图片，并显示复制、校验、清理等进度；公开时还会通知系统相册。它不等同于导出 PDF／ZIP／CBZ，也不会替你执行一次文件导出。

开启时按照系统提示授权：

- 需要存储权限的系统版本，在权限对话框中授权后重新开启。
- 需要“所有文件访问权限”的系统版本，进入系统设置授权后再重新开启。
- 正式版的 Android 10 不支持公开下载，会显示相应提示。

如果提示有下载任务未完成，先等任务完成，或到下载页处理任务后再切换。搬迁期间等待进度结束，以结果提示和开关最终状态判断是否切换成功；出现空间不足、权限或文件错误时，先处理具体原因。

只想把作品另存为文件时，不需要先公开下载图片，直接按[“下载”一章](downloads.md)的导出流程操作即可。

### Windows／Linux：自定义下载位置

桌面端同一位置显示“自定义下载位置”：

1. 开启开关，在目录选择器中选择一个上级文件夹。
2. 应用会在所选位置下使用 **JQViewer** 子目录保存下载内容。
3. 等待已有下载文件迁移，完成后核对设置页显示的当前目录。
4. 关闭开关时，下载位置恢复为应用内部位置，并处理已有下载文件的迁移。

有未完成的下载或导出任务时，桌面端会拒绝切换。已完成下载存在不完整文件、目标目录冲突或迁移校验失败时，也应先处理提示的问题。

迁移需要先复制和校验文件。若结果提示“旧下载目录仍待清理”，说明位置已经切换，但旧目录清理还未结束；应用会在下次启动或再次确认该设置时重试。不要将这类提示理解为已经清理了所有旧副本。

**下载位置、文件导出位置是两套设置。** 想改变 PDF／ZIP／CBZ 的保存位置，使用 [9.7](#file-export-settings) 的“导出位置”。

## 9.5 批量解析的图片 OCR

“批量解析”分组中的“图片 OCR 识别”控制通过上传图片识别 ID 的入口。

开启后，可以在对应解析入口选择图片识别；识别完成后仍应核对文本和 ID，再继续解析。关闭这一开关不会删除解析历史，也不会关闭手动输入文本或 ID 的解析方式。

该开关不是识别结果准确率的设置，也不是下载开关。选择图片、核对识别内容和处理批量结果的步骤，见[“搜索与分类”一章](search-and-categories.md)。

<a id="favorite-export-format"></a>

## 9.6 收藏夹导出格式

“收藏夹导出设置 → 导出格式模板”决定收藏夹导出时每一行文本的格式。默认模板为：

`JM{id}{title}`

| 变量 | 含义 |
| --- | --- |
| `{id}` | 作品 ID |
| `{title}` | 作品标题 |
| `{author}` | 首位作者 |
| `{authors}` | 全部作者，以逗号和空格连接 |
| `{tags}` | 全部标签，以逗号和空格连接 |

例如，假设作品 ID 为 `123456`、标题为“示例作品”、首位作者为“作者甲”，模板 `JM{id} {title} - {author}` 会得到：

`JM123456 示例作品 - 作者甲`

设置页会使用内置示例显示“预览”，可以据此检查分隔符和变量写法。点击“重置为默认”恢复 `JM{id}{title}`；重新导出收藏文本时使用当前模板。

这里生成的是文本行，不决定 PDF、ZIP、CBZ 的目录或文件名，也不支持下一节文件模板的章节变量和标签条件语法。怎样选择作品、执行文本导出或复制，见[“收藏夹”一章](favorites.md)。

<a id="file-export-settings"></a>

## 9.7 文件导出位置与命名设置

“导出设置”用于为后续文件导出提供保存位置和命名规则。输出路径由三部分组成：

`导出位置 / 保存目录模板的结果 / 保存名称模板的结果.扩展名`

| 设置 | 决定什么 | 操作要点 |
| --- | --- | --- |
| 导出位置 | 基础保存目录 | 点击“浏览”，在系统目录选择器中选择并授权 |
| 保存目录模板 | 基础目录下的子目录 | 使用 `/` 表示目录层级 |
| 保存名称模板 | 文件名称，不含扩展名 | 扩展名由实际选择的 PDF、ZIP 或 CBZ 格式决定 |
| 预览 | 以上规则用示例数据组合后的路径 | 用于检查规则，不代表已生成文件 |

### 选择导出位置

先点击“浏览”，完成系统目录选择。应用保存的不只是展示出来的路径文字，还包括访问该目录所需的引用；只看到默认路径文字，不代表已经取得目录权限。

取消目录选择不会设置新目录。选择失败或导出时提示目录不可用，可重新使用“浏览”选择有效目录。

“导出位置”旁的“重置”会清除已保存的目录选择；之后导出仍需要选择有效目录。它不是把已有 PDF／ZIP／CBZ 搬回默认目录的操作。

### 修改目录和名称

默认目录模板为 `{id}`，默认名称模板为：

`【{author}】{title}_{id} {chapterRange}`

例如，假设基础目录为你选择的“漫画导出”，目录模板使用 `{author}/{id}`，名称模板使用 `{id}_{chapterName}`。对于作者甲、ID 为 `123456` 的第 2 话，选择 PDF 格式时，路径结构为：

`漫画导出/作者甲/123456/123456_第2话.pdf`

这里的目录和作品数据只是说明规则的假设例子。设备上的完整基础路径，以目录选择结果为准。

修改模板后，查看输入框下方的渲染结果和组合预览。目录、名称分别有“重置”，只恢复相应模板，不删除已有文件。

模板影响新建导出任务时生成的路径，不会自动重命名或移动过去导出的文件。设置页的组合预览默认使用 PDF 扩展名；真正导出时，以导出面板所选格式和最终路径为准。

路径中的部分非法字符会在生成路径时替换或清理，因此只看变量渲染行还不够，应同时核对组合预览。分卷导出还会在最终名称中加入页码范围，详见[“下载”一章](downloads.md)。

## 9.8 导出模板使用帮助：“食用方法”

从“导出设置”进入“食用方法”，可以查看文件模板的变量、标签条件与示例。该页用于解释规则，不会创建导出任务；执行导出需要回到下载页。

### 基本变量

| 变量 | 含义与注意事项 |
| --- | --- |
| `{id}` | 作品 ID |
| `{title}` | 作品标题 |
| `{chapterId}` | 章节 ID |
| `{chapterName}` | 章节序号名称，例如“第2话”；单行本使用标题 |
| `{chapterRange}` | 选中章节范围，适合用于合并导出的文件名 |
| `{index}` | 章节原始数字序号，不是本次选择中的第几个；没有有效序号时不一定有值 |
| `{chapterTitle}` | 章节原始标题，不保证与“第几话”的序号文字相同 |
| `{pageCount}` | 章节页数；合并导出时为所选章节总页数 |
| `{author}` | 首位作者 |
| `{authors}` | 全部作者，以顿号连接 |
| `{tags}` | 全部标签，以顿号连接 |

合并导出时，`{chapterRange}` 表达所选章节范围，`{pageCount}` 为总页数；章节 ID、序号、标题等单章字段则取规范化输出顺序中的第一章。因此要在名称中表达整组选章，优先使用 `{chapterRange}`，不要把 `{index}` 当成整组的编号。

目录模板与名称模板共用上述文件模板变量；收藏夹文本模板的变量范围和作者、标签连接方式见 [9.6](#favorite-export-format)。

### 标签条件

标签条件只渲染匹配的标签文字：

- `{tag=中文}`：作品有“中文”标签时输出“中文”，否则输出空文本。
- `{tag=中文|單行本}`：或条件；输出其中实际匹配的标签，多个匹配时用顿号连接。
- `{tag=中文&剧情}`：且条件；只有两个标签都存在时，才输出“中文、剧情”。

同一个条件表达式不能混用 `|` 和 `&`。标签匹配区分大小写，并按照实际标签文字判断，不会自动转换同义词或繁简字。

**条件之外的文字会保留。** 例如模板为 `[{tag=中文}]{title}`，作品没有“中文”标签时，标签变量为空，但方括号仍然存在，结果可能是 `[]示例作品`。不要把这个写法理解为自动隐藏整个方括号块。

### 一组简短例子

假设作品标题为“示例作品”，作者为“作者甲”，ID 为 `123456`，章节为“第2话”，页数为 24，标签中有“中文”“剧情”：

| 用途 | 模板 | 渲染结果 |
| --- | --- | --- |
| 按作者和 ID 分目录 | `{author}/{id}` | `作者甲/123456` |
| 简短文件名 | `{id}_{chapterName}` | `123456_第2话` |
| 加页数 | `{title}_{pageCount}页` | `示例作品_24页` |
| 条件前缀 | `[{tag=中文}]{title}` | `[中文]示例作品` |
| 不匹配的条件 | `[{tag=未收录}]{title}` | `[]示例作品` |

表格展示变量渲染结果，没有附加扩展名。完成命名后，再回到导出面板核对实际章节、格式和最终路径；需要导出操作步骤时，见[“下载”一章](downloads.md)。

## 9.9 网络状态与线路选择

可以从“设置 → 网络状态”进入，也可以使用侧边栏的联网状态入口。页面分别显示 API 线路和图片线路，下方还有事件日志。

API 线路用于作品、搜索等接口请求；图片线路用于图片获取。能取得作品信息而图片加载异常时，不能只看 API 线路就判断全部连接正常。

### 查看和选择 API 线路

顶部显示当前线路，以及“自动优选”或“手动固定”模式。

1. 查看在线客户端状态和域名状态。
2. 需要重新探测可达性时，使用“刷新线路状态”。
3. 需要比较延迟时，使用“测量线路延迟”，或对单条线路测速。
4. 要使用某条线路，点击对应的“选择”；要交由客户端选择，切回“自动优选”。

API 测速结果以毫秒显示，可能出现“超时”或“不可达”。只有可达状态而尚未测速的条目，不应当作已经测得具体延迟。

测速用于查看状态，选择线路才会应用相应模式。切换后核对顶部当前线路和模式；遇到切换失败提示时，先查看具体错误，再决定重试或切回自动模式。

### 查看和选择图片线路

“当前图片线路”显示当前 Host 和模式；候选项位于“图片线路探测”。

- 使用“测量图片线路”可测量候选线路；单条线路旁也可单独测速。
- 图片测量结果显示吞吐速度，例如 KB/s 或 MB/s，与 API 的毫秒延迟不是同一种指标。
- 点击某条线路的“选择”可手动固定；切回“自动优选”后由应用管理图片线路。

**在图片线路自动模式下，测量全部候选线路后可能直接应用优选结果。** 手动固定时，测量全部候选用于查看结果，不会因为测速完成就自动改成自动模式；单条测速也不等于选择该线路。

图片自动模式会沿用仍有效的 Host，失效时再后台重选，不代表每次进入页面都会重测并换到另一条线路。切回自动模式时，如果没有可用的现存候选，也可能先执行图片线路测量。

### 初始化、不可用与事件日志

显示“在线客户端正在初始化”时，部分操作暂不可用；显示“当前网络不可用”或“在线客户端暂不可用”时，离线能力仍可使用。线路列表暂时没有内容，不等于本地下载或收藏已经消失。

页面底部“事件日志”用于查看本次线路相关的过程和错误。它与独立的“应用日志”页不同，不能用来代替完整应用日志导出。需要反馈问题时，可按 [9.11](#application-logs) 导出相关日志。

<a id="user-and-login"></a>

## 9.10 用户与登录

通过“设置 → 用户”或侧边栏账号区域进入。未登录时显示“去登录”；登录后显示账号资料。

### 登录

1. 点击“去登录”。
2. 输入用户名和密码。
3. 根据需要选择“下次自动登录”，然后点击“登录”。
4. 登录成功后返回用户页；失败时查看页面提示，并核对账号或联网状态。

“下次自动登录”默认勾选。勾选后应用可在后续启动时尝试自动登录；没有勾选，不影响本次正常登录，但不保留供下次自动登录使用的这次凭据。自动登录仍受当前网络和账号状态影响，不能当作始终在线的保证。

账号区域显示正在登录或需要重试时，可通过侧边栏账号入口重试；首次启动时的账号状态含义见[“初次打开：应用首页与侧边栏”一章](first-open.md)。

### 用户页显示什么

页面会展示可取得的用户名、等级、经验值、在线收藏数量与上限、金币等信息。有个人资料时，还会显示昵称、生日、所在地、职业、自我介绍和网站；没有相应内容时不会填入虚构资料。

本页侧重展示账号信息与登录状态，当前不提供个人资料编辑、注册或找回密码表单。在线收藏的同步与操作见[“收藏夹”一章](favorites.md)，不能把这里的在线收藏数当作本地下载数量。

### 登出

点击“登出”后，确认框会提示切换到离线收藏夹模式。确认后退出登录并返回应用首页，取消则保留当前登录状态。

登出是账号操作，不会替你删除本地收藏、下载文件或历史。需要清理这些数据时，分别使用对应页面的操作。

<a id="application-logs"></a>

## 9.11 查看和导出应用日志

从“设置 → 诊断 → 应用日志”进入。页面显示当前日志文件名、更新时间和日志正文，并自动读取新内容；右上方还有刷新按钮。

正文区域最多保留最近 **500 行**，不能据此判断更早的日志文件已被删除。需要反馈较早发生的问题，或需要完整文件时，使用“导出日志”。

### 导出日志文件

1. 点击“导出日志”，打开文件选择面板。
2. 勾选需要的日志文件，或使用“全选”；面板会显示已选数量、文件大小和“当前日志”标记。
3. 点击“导出选中日志”，在系统目录选择器中选择目标目录。
4. 查看结果提示，区分已导出、跳过和失败的文件，并到目标目录核对。

取消面板或取消目录选择，不会提交这次导出。目标目录本身就是日志目录时，相关文件可能跳过；出现失败数量时，不要把整个操作当作全部成功。

导出日志是将选中的文件保存到指定目录，不会自动把它们发布到 GitHub 或发送给其他人。需要反馈问题时，由你选择要附上的文件。

分享前先查看导出内容，处理与排障无关的个人信息或本地路径，并说明应用版本、系统、发生时间和复现步骤。反馈组织方法见[“常见问题与反馈”一章](troubleshooting.md)。

<a id="about-and-diagnostics"></a>

## 9.12 关于、更新与桌面端诊断

### 关于与检查更新

“关于”页提供当前应用版本、作者、项目仓库、检查更新及发布说明。报告问题时，可从这里确认应用版本。

点击“检查更新”，等待检查结果；发现新版本时，按更新提示决定是否下载。开始后页面会显示下载、校验、准备安装等状态和相应操作：

- 下载阶段可“取消下载”。
- 准备就绪或等待安装权限时，可“安装更新”。
- 失败时查看错误信息，再按当前提供的操作处理。

通知权限、安装授权和桌面端安装方式等平台差异，见[“下载、安装与更新”一章](installation.md)。本节不把“下载结束”与“安装完成”当作同一个状态。

仓库入口可以打开 JQ Viewer 和 JMComic-Api-Java 的项目页面；需要提交反馈时，可使用关于页中的 Issue 指引。

### Desktop 诊断

支持此能力的桌面端在关于页显示“Desktop 诊断”，包括：

- 应用数据、运行缓存、日志等路径信息。
- 下载任务、文件导出任务的总数、进行中及异常数量，以及部分近期失败原因。
- 当前可清理的图片缓存、PDF 页面缓存的数量与大小。

可以使用刷新按钮重新读取诊断信息。这里的路径用于排障概览；查看当前自定义下载位置或文件导出目录时，仍以对应设置项为准。

“清理缓存”会清理图片缓存与 PDF 页面缓存，作用与前面的缓存清理相同，不会删除作品文件或任务记录。**这里的按钮会直接执行清理，没有设置页中的单独确认框。** 操作后查看结果提示和刷新后的资源统计。

Android 不显示该桌面端诊断卡片，可使用应用日志和相应页面的错误提示收集问题信息。
