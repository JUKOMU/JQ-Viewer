# 9.8 导出模板使用帮助：“食用方法” {#98}

从“导出设置”进入“食用方法”，可以查看文件模板的变量、标签条件与示例。该页用于解释规则，不会创建导出任务；执行导出需要回到下载页。

## 基本变量 {#_9}

| 变量 | 含义与注意事项 |
| --- | --- |
| `{id}` | 作品 ID |
| `{title}` | 作品标题 |
| `{chapterId}` | 章节 ID |
| `{chapterName}` | 章节序号名称，例如“第2话”；单行本使用标题 |
| `{chapterRange}` | 选中章节范围，适合用于合并导出的文件名 |
| `{index}` | 章节原始数字序号，不是本次选择中的第几个；没有有效序号时不一定有值 |
| `{chapterTitle}` | 章节原始标题，不保证与“第几话”的序号文字相同 |
| `{pageCount}` | 章节页数；合并导出时为所选章节总页数 |
| `{author}` | 首位作者 |
| `{authors}` | 全部作者，以顿号连接 |
| `{tags}` | 全部标签，以顿号连接 |

合并导出时，`{chapterRange}` 表达所选章节范围，`{pageCount}` 为总页数；章节 ID、序号、标题等单章字段则取规范化输出顺序中的第一章。因此要在名称中表达整组选章，优先使用 `{chapterRange}`，不要把 `{index}` 当成整组的编号。

目录模板与名称模板共用上述文件模板变量；收藏夹文本模板的变量范围和作者、标签连接方式见 [9.6](../settings.md#favorite-export-format)。

## 标签条件 {#_10}

标签条件只渲染匹配的标签文字：

- `{tag=中文}`：作品有“中文”标签时输出“中文”，否则输出空文本。
- `{tag=中文|單行本}`：或条件；输出其中实际匹配的标签，多个匹配时用顿号连接。
- `{tag=中文&剧情}`：且条件；只有两个标签都存在时，才输出“中文、剧情”。

同一个条件表达式不能混用 `|` 和 `&`。标签匹配区分大小写，并按照实际标签文字判断，不会自动转换同义词或繁简字。

**条件之外的文字会保留。** 例如模板为 `[{tag=中文}]{title}`，作品没有“中文”标签时，标签变量为空，但方括号仍然存在，结果可能是 `[]示例作品`。不要把这个写法理解为自动隐藏整个方括号块。

## 一组简短例子 {#_11}

假设作品标题为“示例作品”，作者为“作者甲”，ID 为 `123456`，章节为“第2话”，页数为 24，标签中有“中文”“剧情”：

| 用途 | 模板 | 渲染结果 |
| --- | --- | --- |
| 按作者和 ID 分目录 | `{author}/{id}` | `作者甲/123456` |
| 简短文件名 | `{id}_{chapterName}` | `123456_第2话` |
| 加页数 | `{title}_{pageCount}页` | `示例作品_24页` |
| 条件前缀 | `[{tag=中文}]{title}` | `[中文]示例作品` |
| 不匹配的条件 | `[{tag=未收录}]{title}` | `[]示例作品` |

表格展示变量渲染结果，没有附加扩展名。完成命名后，再回到导出面板核对实际章节、格式和最终路径；需要导出操作步骤时，见[“下载”一章](../downloads.md)。
