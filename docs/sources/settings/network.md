# 9.9 网络状态与线路选择 {#99}

可以从“设置 → 网络状态”进入，也可以使用侧边栏的联网状态入口。页面分别显示 API 线路和图片线路，下方还有事件日志。

API 线路用于作品、搜索等接口请求；图片线路用于图片获取。能取得作品信息而图片加载异常时，不能只看 API 线路就判断全部连接正常。

## 查看和选择 API 线路 {#api}

顶部显示当前线路，以及“自动优选”或“手动固定”模式。

1. 查看在线客户端状态和域名状态。
2. 需要重新探测可达性时，使用“刷新线路状态”。
3. 需要比较延迟时，使用“测量线路延迟”，或对单条线路测速。
4. 要使用某条线路，点击对应的“选择”；要交由客户端选择，切回“自动优选”。

API 测速结果以毫秒显示，可能出现“超时”或“不可达”。只有可达状态而尚未测速的条目，不应当作已经测得具体延迟。

测速用于查看状态，选择线路才会应用相应模式。切换后核对顶部当前线路和模式；遇到切换失败提示时，先查看具体错误，再决定重试或切回自动模式。

## 查看和选择图片线路 {#_12}

“当前图片线路”显示当前 Host 和模式；候选项位于“图片线路探测”。

- 使用“测量图片线路”可测量候选线路；单条线路旁也可单独测速。
- 图片测量结果显示吞吐速度，例如 KB/s 或 MB/s，与 API 的毫秒延迟不是同一种指标。
- 点击某条线路的“选择”可手动固定；切回“自动优选”后由应用管理图片线路。

**在图片线路自动模式下，测量全部候选线路后可能直接应用优选结果。** 手动固定时，测量全部候选用于查看结果，不会因为测速完成就自动改成自动模式；单条测速也不等于选择该线路。

图片自动模式会沿用仍有效的 Host，失效时再后台重选，不代表每次进入页面都会重测并换到另一条线路。切回自动模式时，如果没有可用的现存候选，也可能先执行图片线路测量。

## 初始化、不可用与事件日志 {#_13}

显示“在线客户端正在初始化”时，部分操作暂不可用；显示“当前网络不可用”或“在线客户端暂不可用”时，离线能力仍可使用。线路列表暂时没有内容，不等于本地下载或收藏已经消失。

页面底部“事件日志”用于查看本次线路相关的过程和错误。它与独立的“应用日志”页不同，不能用来代替完整应用日志导出。需要反馈问题时，可按 [9.11](logs.md#application-logs) 导出相关日志。
