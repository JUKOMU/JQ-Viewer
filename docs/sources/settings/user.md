# 9.10 用户与登录 {#910}

通过“设置 → 用户”或侧边栏账号区域进入。未登录时显示“去登录”；登录后显示账号资料。

## 登录 {#_14}

1. 点击“去登录”。
2. 输入用户名和密码。
3. 根据需要选择“下次自动登录”，然后点击“登录”。
4. 登录成功后返回用户页；失败时查看页面提示，并核对账号或联网状态。

“下次自动登录”默认勾选。勾选后应用可在后续启动时尝试自动登录；没有勾选，不影响本次正常登录，但不保留供下次自动登录使用的这次凭据。自动登录仍受当前网络和账号状态影响，不能当作始终在线的保证。

账号区域显示正在登录或需要重试时，可通过侧边栏账号入口重试；首次启动时的账号状态含义见[“初次打开：应用首页与侧边栏”一章](../first-open.md)。

## 用户页显示什么 {#_15}

页面会展示可取得的用户名、等级、经验值、在线收藏数量与上限、金币等信息。有个人资料时，还会显示昵称、生日、所在地、职业、自我介绍和网站；没有相应内容时不会填入虚构资料。

本页侧重展示账号信息与登录状态，当前不提供个人资料编辑、注册或找回密码表单。在线收藏的同步与操作见[“收藏夹”一章](../favorites.md)，不能把这里的在线收藏数当作本地下载数量。

## 登出 {#_16}

点击“登出”后，确认框会提示切换到离线收藏夹模式。确认后退出登录并返回应用首页，取消则保留当前登录状态。

登出是账号操作，不会替你删除本地收藏、下载文件或历史。需要清理这些数据时，分别使用对应页面的操作。
